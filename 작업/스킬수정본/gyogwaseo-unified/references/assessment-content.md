# 교과서 FINAL 기반 문제 제작·검수

차례: 기준 파일 → 문항 구성 → 원문 가공 → 문항 정보 → 선지 품질 → 자체검수·인계 → 독립 검수·확정.

내용·학습 단위·추가 검수 결정은 공통 기준을 따른다. 공통 원고 검사와 MASTER 조립 연결은 runtime-and-data.md를 따른다.

## 1. 제작 기준 파일 자동 탐색

사용자가 해당 과의 문제 제작을 요청하면 현재 지정·연결된 해당 교과서 작업폴더에서 최신 유효 해석·분석 FINAL을 찾아 실제 내용을 읽고, 워크북과 문제를 함께 제작한다. Google Drive 사용과 로컬 저장·플랫폼 차이는 `workflow.md`를 따른다. 이 문서의 [교재명]_UNITXX_FINAL.txt 등은 신규 파일의 기본 표기이며, 예를 들어 신규 4과는 UNIT04로 표기한다. 기존에 확정된 LESSON04·4과 등 과 표기가 있으면 유지하고 `workflow.md`의 파일명 규칙을 따른다. 프로젝트의 권위 원문과 복원에 필요한 경우 정답 자료도 함께 확인한다. 권위 원문은 해당 교과서 PDF 또는 사용자가 원본으로 지정한 DOCX·이미지·TXT이며 파일 형식만으로 권위를 바꾸지 않는다.

내용의 우선순위:

1. 권위 교과서 원문과 필요한 정답에 따라 정상 복원한 원문: 영어 지문과 사실의 기준.
2. [교재명]_UNITXX_FINAL.txt: 확정된 해석·분석·구문으로 해석하기·유의어/반의어 등 학습 데이터.
3. 현재 교과서 문제 제작 기준: 문항 구성·출제·검수 방식.

- 최신 사용자 지시가 작업 범위를 결정한다. 해석·분석 FINAL이 없으면 문제 제작을 시작하지 않는다. 정확한 누락 파일명과 해석·분석 제작 또는 독립 검수가 먼저 필요한 상태를 보고하고 해당 단계로 인계한다. 기존 혼공해석지만 있는 상태를 해석·분석 FINAL 확정으로 간주하지 않는다. 신규 분석 제작에 FINAL을 선행 조건으로 요구하지 않는다.
- 이전 QC_HANDOFF, 제작 중간본, 구버전 DOCX, 과거에 만든 문제를 FINAL 대신 사용하지 않는다. 사용자에게 재업로드나 수동 파일 이동을 요구하지 않는다.
- 과목·출판사·저자·과·본문 또는 추가 읽기 영역·문단과 문장 범위를 확인하여 다른 교과서의 같은 과 파일을 배제한다. 교육과정·판본은 원본에서 확인되는 식별 정보를 유지한다. 정답 자료도 해당 본문과 실제로 같은지 확인한다.
- 원본의 문제용 오류를 FINAL과 다르다는 이유로 다시 오류형으로 되돌리지 않는다. 정상 복원에 필요한 정답 근거가 없으면 추정하지 말고 빠진 자료를 보고한다. 정상 교과서 본문에는 별도의 정답지가 없다는 이유만으로 작업을 중단하지 않는다.
- FINAL의 확정 학습 데이터가 원문과 명백히 충돌하면 그 부분으로 출제하지 않는다. 충돌 위치를 보고하여 해당 FINAL의 수정·재검증을 먼저 받는다. 문제 제작팀이 해석·분석 FINAL을 임의로 덮어쓰지 않는다.

## 2. 기본 구성과 문항 편성표

- **공통 학습 단위 = 해석지 단위 = 분석 단위 = 워크북 1개**로 맞춘다. `editorial-core.md`의 6문장 이하·소제목 전체 묶기와 무소제목 확인 규칙으로 단위를 먼저 확정한다. 각 공통 단위의 해석·분석 FINAL에서 확정한 유의어·반의어 3세트를 그 공통 단위 워크북의 뜻 쓰기와 실전문제 선택지 재료로 사용한다. 워크북에는 공통 단위마다 실전문제 1문항과 핵심 문장 2개 다시 해석하기를 둔다. 원문의 단락·문장 순서와 각 문장의 출처 번호를 유지한다.
- SOURCE는 과목·출판사·저자·과와 실제 영역으로 식별되는 독립 본문을 가리킨다. 문서 머리의 교과서 식별 정보와 SOURCE를 합쳐 전체 출처를 식별할 수 있으면 SOURCE에는 `UNIT04-본문` 같은 실제 영역 식별자를 사용한다. 교과서가 바뀐 문항을 같은 출처로 합치지 않는다. 같은 독립 본문에서 낸 모든 발췌 문항은 동일한 SOURCE를 사용한다. 공통 단위별 학습단위로 나뉘어 있어도 동일 본문이라는 출처 관계는 유지한다. 문제용 실제 범위는 별도 SOURCE_RANGE에 기록하며, 발췌 위치를 바꿔 새 SOURCE로 세지 않는다. 별도로 실린 추가 읽기는 실제로 독립된 본문이고 출제 범위에 포함된 경우에만 별도 SOURCE로 삼는다.
- 워크북 실전문제는 모든 과목에서 **공통 단위별 1문항**이다. 한 과의 확정 출제 공통 단위가 P개이면 워크북 실전문제는 P문항이다. 미니 모의고사는 과목별로 아래 수량을 적용한다. 워크북의 다섯 단계와 답안 형식은 `workbook.md`를 따른다. 워크북 실전문제를 별도 변형문제로 복제하거나 모의 한 회로 세지 않는다.

| 과목 | 모의 회당 문항 수 | 회차 | 모의 총수 | 워크북 포함 객관식 총수 |
|---|---:|---:|---:|---|
| 공통영어1 | 5 | 3 | 15 | P + 15 |
| 공통영어2 | 5 | 3 | 15 | P + 15 |
| 영어II(영어2) | 7 | 3 | 21 | P + 21 |

- 공통영어2와 영어II(영어2)를 같은 과목으로 취급하지 않는다. 원본의 정식 과목명을 확인해 위 표를 적용한다. 그 밖의 교과목은 기존 기본값인 5문항 × 3회분을 사용하되, 사용자 지시나 현재 교재의 승인 구성이 있으면 우선한다.
- 원문의 실제 단락 경계와 공통 학습 단위는 구별한다. 원문 단락이 6문장 이하이면 그 소제목 전체를 묶고, 소제목이 없으면 원문으로 범위를 확인한다. 줄바꿈·쪽 나눔·제목만으로 단락을 만들거나 문항 수에 맞춰 원문을 재분할하지 않는다. 문단 표시가 없는 원문은 전체를 읽고 의미 경계의 근거를 기록한다. 세부 단위 확정은 `analysis-content.md`를 따르며 문제 제작에서는 FINAL의 확정 단위를 이어 쓴다.
- 워크북은 공통 단위별 1문항과 해당 단위의 유반 의미 학습 목표를 유지하되, 문제용 지문은 과의 출제 범위 안에서 학습 단위 경계와 무관하게 적합한 연속 범위를 선택한다. 보고된 유반 0세트 단위에는 아래 5절의 일반 실전문제 예외를 적용한다. 그 단위의 원문 문장을 반드시 포함해야 한다는 조건은 두지 않는다. 편성표에는 학습 어휘를 가져온 공통 단위와 실제 SOURCE_RANGE를 구분한다. 서로 독립된 본문을 이어 붙이지 않는다. 해당 학습 어휘의 의미 판단과 자족적인 문항이 성립하지 않으면 지문 범위·유형·발문을 다시 설계한다.
- 사용자 명시 수량·배분·회차 → 현재 교재의 승인 구성표 순으로 적용한다. 둘 다 미지정인 부분만 아래 절차로 편성한다. 명시적인 부분 제작·추가 회차 요청이 기본 구성보다 우선한다.

### 제작·검수가 공유할 편성 절차

1. 최신 FINAL과 원본에서 현재 과의 독립 본문, 확정 공통 단위 목록과 수 P, 출처 문장 번호, 출제 범위와 실제 원유형을 확인한다. 공통 단위·해석지 학습단위·분석단위·워크북이 1:1로 대응하고 각 공통 단위의 유반 3세트와 핵심 2문장이 확정됐는지 확인한다. 짧은 공통 단위의 학습 항목 수량은 `analysis-content.md`·`workbook.md`의 승인 예외와 사용자 보고 규칙을 적용해 실제 확정 수로 대조한다. 일반 교과서 본문에 원유형이 없으면 없음으로 기록한다. 단원의 학습 목표나 내용에 맞춰 원유형을 임의로 만들지 않는다.
2. 각 공통 단위·출제 범위에 적합한 유형을 검토한다. 실제 원유형과 어법을 제외하고, 아래의 원문 보존·발췌 조건, 충분한 근거, 단일 정답을 만족하는 후보만 남긴다. 워크북은 해당 공통 단위의 유반 의미를 영어 선택지로 판단하는 유형만 남기되, 보고된 유반 0세트는 학습 어휘 연결 없이 일반 실전문제로 설계한다. 나머지 독해 유형은 미니 모의고사에서 검토한다. FINAL의 구문으로 해석하기는 구조 참고일 뿐 어법 출제 허용이 아니다.
3. 워크북에는 대상 공통 단위마다 정확히 1문항을 원문 순서로 배정한다. 별도 모의 1·2·3회에는 공통영어1·2는 각각 5문항, 영어II는 각각 7문항을 배정한다. 모의 총 15문항 또는 21문항은 확정 범위의 주요 내용과 단락에 고르게 배분하되 매회 모든 단락을 넣거나 회당 문항 수만큼의 독립 본문을 확보하는 조건을 강제하지 않는다. 같은 본문의 서로 다른 단락·발췌 구간을 활용할 수 있다. 각 회차의 공통 단위별 포함 여부는 편성표에 명시한다.
4. 실제 제작할 문항을 `Q 번호 | SET | SOURCE | 대상 공통 단위(학습단위) | SOURCE_RANGE | 영어 본문 단어 수 | TYPE`의 표로 작성하고 SET별·SOURCE별·대상 공통 단위별·유형별 수와 총계를 실제 행 수로 계산한다. 워크북 P개·실전문제 P문항과 과목별 모의 수량을 확인한다. 공통영어1·2는 모의 각 5문항·총 15문항·전체 P + 15문항, 영어II는 모의 각 7문항·총 21문항·전체 P + 21문항이어야 한다. SOURCE_RANGE에는 실제 영역 안의 문단·출처 문장 범위를 적고, 발췌 없이 전문을 쓰면 전체 범위를 적는다. 낱말·유반 뜻 쓰기·구문 결합 연습·핵심 2문장 활동은 Q 문항 수에 포함하지 않는다. 제외나 사용자 지정 수량 예외가 있으면 이유를 한 줄로 기록한다.
5. 이 표를 원고 밖의 현재 수정인계/작업 기록에 보관하고 제작과 독립 검수에서 동일하게 사용한다. 기록 위치는 `workflow.md`를 따른다. 기존 유효 편성표가 있으면 재검수 중 취향에 따라 재편성하지 않는다.
6. 제작 중 유형 변경이 필요하면 해당 행과 연결된 문제·정답·해설을 함께 수정한다. 사용자 확정 수량을 바꿔야 하거나 적합한 유형으로 유일정답을 만들 수 없으면 미해결 범위를 보고하고 그 상태를 완료로 확정하지 않는다. 일반적인 미지정 부분 편성이나 허용된 유형 반복마다 사용자 확인을 요구하지 않는다.

### 유형 분류와 중복

TYPE은 아래 표준 명칭을 쓴다. 이름만 바꿔 다른 유형처럼 세지 않는다.

| TYPE | 같은 유형으로 계산할 변형 |
|---|---|
| 제목 | 제목 찾기·가장 적절한 제목 |
| 주제 | 중심 화제·주제 찾기 |
| 요지 | 글의 핵심 내용·요지 찾기 |
| 주장 | 필자의 주장·당위적 의견 |
| 목적 | 글을 쓴 목적 |
| 심경·분위기 | 인물의 심경·심경 변화·글의 분위기 |
| 내용 | 내용 일치·내용 불일치 |
| 함축 의미 | 밑줄 의미·문맥상 표현의 의미 |
| 빈칸 | 단어·구·절 빈칸 추론 |
| 요약 | 요약문 완성 |
| 무관한 문장 | 흐름과 관계없는 문장 |
| 삽입 | 주어진 문장 넣기 |
| 순서 | 글의 순서 배열 |
| 어휘 | 문맥상 부적절한 어휘 |

- 워크북 실전문제는 제목·주제·요지·주장·목적·심경·분위기·내용·함축 의미·빈칸·요약 등의 후보 중 **해당 공통 단위에서 배운 유반을 영어 선택지로 사용하고 그 의미를 알아야 판단할 수 있는 유형만** 선택한다. 보고된 유반 0세트에서만 학습 어휘 연결 조건을 해제하고 위 후보의 일반 실전문제로 출제한다. 유형명만 이 목록에 속한다고 통과시키지 않는다. 순서·삽입·무관한 문장, 본문 번호로 답하는 어휘 등 이 목표에 맞지 않는 유형은 미니 모의고사에서 다룬다.
- TYPE 반복은 같은 SOURCE의 **동일 발췌 구간을 포함하여** 워크북과 모든 모의 회차에서 허용한다. 원유형이 실제로 있을 때만 같은 분류로 정규화해 제외하며, 없음은 제외할 유형이 없다는 뜻이다. 유형 반복을 허용해도 같은 문제를 복제해 별도 문항 수를 채우지 않는다.
- 수능 독해 유형을 가능한 한 다양하게 분산하되, 워크북의 유반 의미 학습 목표와 각 지문의 적합성·유일정답을 우선한다. 미니 모의고사에서는 순서·삽입·무관한 문장·어휘 등 워크북 밖의 적합한 유형도 활용한다. 도표·안내문 등 실제 원본 자료가 필요한 유형은 해당 자료 없이 억지로 만들지 않는다. 어법은 제외한다. 유형별 고정 비율이나 회차별 전 유형 포함을 강제하지 않고 실제 유형 분포를 편성표에서 확인한다.
- 원유형이 위 목록 밖이면 그 실제 유형을 기록하되 목록 안의 유형으로 억지 변환하지 않는다. 사용자 지정 신규 유형은 명시 지시를 따르고 분류 기준을 기록한다.
- 적합한 서로 다른 유형이 부족하면 같은 유형을 반복하거나 다른 대상 공통 단위·구간을 검토한다. 다양성을 위해 출제 가공이나 원문 사실을 바꾸어 수를 채우지 않는다.

### 매회 마지막 두 문항의 공유 장문

- 각 미니 모의고사 마지막 두 문항은 하나의 장문 지문을 공유하는 연결 문항으로 편성한다. 기존 회당 총수 안에 포함하므로 영어2는 일반 5문항 + 장문 2문항, 공통영어1·2는 일반 3문항 + 장문 2문항이다. 장문을 별도 추가 문항으로 세거나 각 문항에 같은 지문을 두 번 싣지 않는다.
- 공통 구현의 기본 조합은 공식 학력평가 41~42번과 같은 **제목 + 문맥 어휘**다. 이는 사용자가 세부 유형을 직접 선택했다는 뜻이 아니라, 확정한 ‘공유 장문 2문항’을 구현하는 기본 편성이다. 다른 조합을 명시적으로 요청받으면 공유 원문·필수 표시·답안 연결을 함께 설계·검수한다.
- `assessment.passage_groups`에 `id, kind:"long_reading", set_id, question_ids:[제목ID,어휘ID], passage_question_id:어휘ID`를 기록한다. 두 학생 문항에 같은 `passage_group_id`를 연결한다. 각 문항의 기존 TYPE·ID·번호·빠른 정답·해설은 유지한다. 새 TYPE인 ‘장문’을 만들어 하위 문항을 합치지 않는다.
- 두 문항의 권위 원문, 실제 연속 범위와 복원 결과는 완전히 같아야 한다. 각 문항의 원고 `passage`는 자신의 원문 변형 결과를 보존하고, 실제 공유 출력에는 어휘 문항의 지문·다섯 번호·밑줄을 한 번 사용한다. `check_book.py`의 `passage_group_views`가 이 출력 범위를 명시한다. 장문은 원문의 단락 구분을 유지할 수 있다.
- 어휘의 오류 표현 하나가 제목의 정답 근거를 훼손하지 않는지 두 문항을 공유 지문에 함께 대입해 독립 검수한다. 학생용 어휘 표적은 공통 규칙의 ①~⑤를 사용하고 해설·빠른 정답과 대응시킨다.

## 3. 원문을 보존하는 문제용 가공

워크북 실전문제와 미니 모의고사의 지문은 **실제 발문과 정답·네 오답 판단에 필요한 자족적인 연속 범위**를 선택한다. 과의 출제 범위 안에서 해석지의 학습 단위 경계에 묶이지 않는다. 마지막 단락의 주제만 평가할 때 관련 없는 앞 단락을 덧붙이지 않는다. 동시에 아래 학년별 실제 모의고사 분량에 비해 지나치게 짧아서는 안 된다. 충분한 범위를 선택해야 한다면 그 제시 범위 전체를 평가하도록 발문·선지·정답·해설을 다시 설계한다. 선택한 범위 안의 문장은 모두 제시하며, 문제용 발췌 때문에 공통 학습 단위나 SOURCE를 새로 나누지 않는다.

- **고정 100단어 하한을 폐기한다.** 공통영어1·2는 고1, 영어2(영어II·영어Ⅱ)는 고2의 실제 학력평가에서 같은 유형의 지문 분량과 정보 전개를 비교한다. 이 과목의 공백·로마숫자 표기 차이는 같은 공통 정규화로 학년과 모의 회당 문항 수(공통영어1·2는 5, 영어2는 7)를 함께 판단하며, 원래 표지 표기는 변경하지 않는다. 다른 과목은 확인된 비교 학년을 `assessment.scope.reference_grade`에 명시한다. 과목명을 근거 없이 고1·고2로 추정하지 않는다.
- `assets/exam-length-profile.json`은 EBSi 공식 제공 2026년 3·6·9월 시험지의 동학년·동유형 실측 비교 자료다. 시험별 URL·PDF 해시·문항 번호·단어 수가 연결되어 있다. 각 `question_sources[].length_review`에 현재 `profile_id`, `grade`, 해당 학년·유형의 실제 `benchmark_ids` 세 개 전부와 구체적인 `rationale`를 기록한다. 장문 두 문항은 일반 제목/어휘 표본 대신 `long41_42` 표본을 사용한다. 일부러 짧은 표본 하나만 고르지 않는다.
- 표본은 공식 최소 분량 규정이 아니며 새 고정 하한·상한으로 선언하지 않는다. 동유형 표본보다 짧은 원고는 `independent_review_required:true`를 기록하고 실제 독립 검수 대상으로 남긴다. 검사기는 `NEEDS_INDEPENDENT_REVIEW`를 반환하며, 이 필드나 글자 수만으로 충분한 길이라고 승인하지 않는다. 학년 수준·정보량·논리 전개까지 검토해 너무 짧으면 적합한 연속 범위와 문항 전체를 다시 설계한다. 관련 없는 단락으로 길이를 채우거나 교과서에 없는 문장을 창작하지 않는다.
- 원문 단어 수는 빈칸·어휘 교체 전 정상형 원문을 대상으로 한다. 레이아웃 줄바꿈을 정리한 뒤 공백 단위로 세고 축약형·하이픈 표현은 한 어절, 숫자는 공백 단위로 포함하며 문장부호만 있는 항목은 제외한다. 발문·선지·제목·문항 번호·각주·추가 요약문은 제외한다. 순서는 GIVEN+BLOCKS, 삽입은 GIVEN+PASSAGE를 중복 없이 합산하며 공유 장문은 지문 한 벌만 센다. 표본 비교용 `assessment_word_count`는 실제 시험지와 동일하게 무관 문장 유형의 출제용 추가 문장까지 포함한다. 정상형 `word_count`와 이 비교용 수를 혼동하지 않는다.
- 일반 문제 지문은 원래 여러 단락이어도 **한 문단·내부 수동 줄바꿈 없음**으로 출력한다. 문장 사이에는 필요한 공백을 유지한다. 권위 원문·출처 범위·원문 변형 위치는 바꾸지 않고 조판 단계의 표시만 합친다. 순서 문제의 주어진 글과 A/B/C 구획, 삽입 문제의 주어진 문장 박스는 유형의 필수 구조이므로 유지하되 각 블록 내부는 한 문단으로 출력한다. 공유 장문은 원문의 단락 구분을 유지할 수 있다.
- 문서 머리와 SOURCE를 합쳐 해당 교과서의 과목·출판사·저자·과·실제 본문 또는 추가 읽기 영역을 식별하고, SOURCE_RANGE에는 그 영역 안의 정확한 문단·문장 범위를 표시한다. 원문에 문단·문장 번호가 없으면 원문 순서로 대응 번호를 정해 FINAL과 편성표에서 일관되게 사용한다. 대명사 지시 대상·논리 연결·정답 및 네 오답의 판단 근거가 발췌 범위 안에 충분히 남아야 한다.
- 여러 위치의 문장을 임의로 이어 붙이거나 길이를 채우기 위해 문장을 창작하지 않는다. 교과서 외 자료에는 이 예외를 적용하지 않는다.
- 범위 안의 문장을 삭제·축약·개작하여 길이를 줄이거나 지시 대상을 보충하지 않는다. 발췌만으로 판단 근거가 자족하지 않으면 연속 범위를 넓히거나 전문을 사용한다. 그것으로도 해당 유형이 성립하지 않으면 다른 적합한 유형을 선택한다.

정답 근거를 만들기 위해 본문의 사실·인과·주체·문장 구조를 임의로 바꾸지 않는다. 아래 출제 가공만 허용하며, 가공을 되돌리면 정상형 원문과 일치해야 한다. 교과서 발췌 문항의 복원 기준은 허용된 발췌 원문이다.

| 유형 | 허용 가공과 복원 |
|---|---|
| 제목·주제·요지·주장·목적·심경·분위기·내용 | 정상형 원문 그대로 사용 |
| 함축 의미 | 원문 표현을 지정하고 발문과 TARGET에 동일한 표현 기록. 본문과 발문 안 해당 표현 모두 밑줄. 본문 개작 금지 |
| 빈칸 | 원표현 한 곳을 밑줄 16자로 대체. 원표현을 돌려놓으면 원문 |
| 요약 | 원문 뒤 [요약문]과 (A)/(B) 빈칸 추가. 요약문을 제거하면 원문 |
| 무관한 문장 | 같은 화제의 이웃 소재 문장 1개 추가, ①~⑤ 표시. 추가 문장과 번호를 제거하면 원문 |
| 삽입 | 원문 한 문장을 GIVEN으로 분리. 정답 위치에 넣고 번호를 제거하면 원문 |
| 순서 | 주어진 첫 글을 고정하고 나머지를 A/B/C로 분리. 선택지는 ①ACB ②BAC ③BCA ④CAB ⑤CBA. 정답 배열이면 원문 |
| 어휘 | 어휘 한 곳만 최소 교체하고 다섯 표적 모두에 번호·밑줄 지정. 원어휘로 복원하면 원문 |

- 빈칸의 정답 선지는 원표현의 문맥상 유의 표현을 사용한다. 원문 복원에는 원표현을 사용하며 정답 선지와 혼동하지 않는다.
- 빈칸의 긴 정답 표현을 본문의 다른 곳에 그대로 남겨 단순 글자 맞추기로 답을 노출하지 않는다.
- 무관한 문장의 추가 문장과 어휘 문항의 틀린 어휘는 출제용 가공이다. 이를 원문의 사실이나 정답 근거로 취급하지 않는다.
- 요약은 본문 관계를 보존하며 과도한 일반화를 하지 않는다. 제목은 제시된 글 전체를 포괄한다. 교과서 발췌 문제도 정답 근거를 발췌 밖 내용에 의존하지 않는다.
- 순서·삽입의 지시어, 생략된 대상, 사건 선후를 확인한다. 연결어나 시제 하나만으로 유일한 정답이라고 단정하지 않는다.
- 순서의 복원 배열이 ABC이면 위 고정 다섯 선택지에 답이 없으므로 원문을 바꾸지 말고 A/B/C 이름을 재배정한다. 선택지·정답·해설·빠른 정답을 함께 다시 대조한다. 다섯 순열을 임의로 고르거나 선지 순서를 섞지 않는다.
- 구체적인 한 사실·방법을 발문에서 미리 지정하는 내용 문제 대신 `다음 글의 내용과 일치하는 것은?` 또는 `다음 글의 내용과 일치하지 않는 것은?`을 사용한다. 발문만 교체하지 말고 다섯 선지와 정오 판단 범위·근거·해설까지 재설계한다.
- 함축 의미 문항은 `questions[].prompt_underlines:[[start,end]]`로 발문 문자열 안의 실제 원문 표현 위치 한 곳을 기록한다. 그 범위의 문자열은 TARGET과 정확히 같아야 한다. 본문 표적과 발문 인용의 밑줄을 저장된 DOCX에서도 각각 확인한다. 문맥 어휘의 ①~⑤ 다섯 표적은 번호만 표시하지 말고 해당 영어 낱말에 모두 밑줄을 적용한다.

## 4. 문항 정보

references/handoff-format.md의 문제 전용 블록을 사용한다.

아래 Q 블록의 정답·근거·해설·오답 분석 요건은 실전문제에 적용한다. 워크북의 오늘의 낱말·유의어/반의어 정답은 번호와 뜻만 담은 간단한 표로, 핵심 문장 정답은 확정 학습단위별 실제 선정 수(기본 2개)에 맞는 우리말 해석만 적으며 별도 근거·해설을 붙이지 않는다.

- Q01부터 중복 없는 문항 번호, SET(워크북 실전문제/모의 회차), SOURCE, SOURCE_RANGE, TYPE, QUESTION을 적는다. SOURCE는 독립 본문 식별에, SOURCE_RANGE는 해당 문항의 실제 출제 범위 대조에 사용한다. 유형 분포와 문항 복제 여부는 SOURCE와 실제 발췌 구간·핵심 근거를 함께 확인한다.
- PASSAGE는 선택한 연속 출제 범위의 전문이다. 순서는 GIVEN+BLOCKS, 삽입은 GIVEN+PASSAGE 전체가 출제 범위의 정상형 원문을 보존하도록 구성한다. 공유 장문은 같은 원문의 각 문항 복원값과 실제 공유 출력용 owner 지문을 구분해 보존한다.
- 필요한 GIVEN·BLOCKS·TARGET·빈칸·본문 ①~⑤ 위치를 생략하지 않는다.
- 워크북 실전문제와 미니 모의고사의 선택지는 영어로 작성하고 한국어 선택지는 만들지 않는다. 별도 선지는 CHOICES에 ①~⑤ 한 줄씩 적는다. 미니 모의고사의 본문 번호형 무관·삽입·어휘 유형이나 순서 배열의 기호는 해당 유형의 표기를 유지하며 억지로 영어 문장을 덧붙이지 않는다. 본문 번호가 선택지이면 목록을 다시 출력하지 않는다. 이 표기 예외를 워크북의 유반 활용 영어 선택지 조건을 피하는 데 사용하지 않는다.
- ANSWER·EVIDENCE·EXPLANATION은 반드시 포함한다. EVIDENCE는 실제 원문 표현과 그 위치 또는 논리 연결을 구체적으로 밝힌다.
- 5지선다형의 WRONG_ANALYSIS에는 정답을 제외한 네 선지 각각의 배제 근거를 모두 적는다. 본문 번호로 답하는 유형도 같다.
- 영어 선지는 CHOICES_KR에 같은 번호의 한국어 해석을 제공한다. 해설지에는 CHOICES의 원문과 CHOICES_KR를 번호별로 결합해 반드시 `① 영어 선택지 전체 (한국어 해석)` 형식으로 표시한다. 정답을 포함한 다섯 선지 모두 영어 원문을 생략·요약하지 않고, 바로 뒤 괄호 안에 해당 해석을 넣는다. 구·낱말·요약문 빈칸 쌍도 실제 선택지 전체를 보존한다. 한국어 해석만 단독으로 나열하지 않는다. 번역은 해설 영역에만 두며 학생용 선택지에는 붙이지 않는다.
- 한국어는 발문·정답 근거·해설·오답 분석과 해설 영역의 선택지 번역에 사용할 수 있다. 학생용 영어 선택지에 한국어 번역을 붙이지 않는다. 본문 번호가 선택지인 유형에는 별도 선지 목록을 만들지 않는다.
- 모든 문제에서 VOCAB_GLOSS를 사용하지 않는다. 기존 단어 각주는 제목과 내용을 모두 삭제한다. 단어 각주는 혼공해석지에만 제공한다.

## 5. 선지 품질과 학생 수준

- 대상은 SKILL.md의 기본 수준과 사용자 지정 학년을 적용한다. 내신 3등급 이하〔5등급제 기준〕와 모의고사 5등급 이하를 혼동하지 않는다. 고2 영어II 작업을 고1 과목으로 바꾸지 않는다.
- **워크북 실전문제의 학습 목표:** 앞선 같은 공통 단위의 지문분석지와 유의어·반의어 활동에서 배운 어휘의 의미를 제대로 학습했는지 평가한다. 유반 세트가 있는 워크북 실전문제는 해당 공통 단위 FINAL의 실제 확정 유반 세트(기본 3세트, 짧은 공통 단위 예외는 실제 수)를 선택지 재료로 삼아 영어 선택지를 만든다. 단순히 배운 낱말을 넣는 데 그치지 말고, 그 의미와 문맥상 쓰임을 알아야 선택지를 판단할 수 있도록 구성한다. 한 문항에 3세트 전부 또는 9어휘 전부를 넣는 등 사용자가 정하지 않은 활용 최소 수량을 강제하지 않는다. **원문 근거와 실제 수량 부족을 보고한 유반 0세트 단위는 일반 실전문제로 출제한다.** 오늘의 낱말을 억지로 연결하거나 유반을 지어내지 않는다. 이 예외에서도 영어 선택지·출제 범위·공식 지문 분량 비교·유일정답·해설 요건을 동일하게 적용한다.
- **정답·오답 역할:** ‘유의어는 정답, 반의어는 오답’으로 고정하거나 그 역할을 일률적으로 뒤집지 않는다. 발문과 본문 문맥, 선택지 전체의 의미에 따라 반의어도 정답이 될 수 있고 유의어도 오답이 될 수 있도록 설계한다. 유의어·반의어라는 분류 자체를 정오 판단 근거로 삼지 않는다. 역할별 비율이나 교대 순서를 기계적으로 강제하지 않는다. 역할을 바꾸기 위해 원문 의미를 왜곡하거나 반의어를 문맥상 동의어인 것처럼 취급하지 않으며, 정답은 항상 하나만 성립해야 한다.
- **제작·검수 확인:** 워크북 문항별로 활용한 학습 어휘와 선택지 위치를 편성표 또는 수정인계에 기록한다. 자체검수와 독립검수에서 학습 어휘와의 대응, 영어 선택지, 실제 의미 판단의 필요성, 정답·오답 역할의 고정 여부를 확인한다. 해설에는 해당 선택지가 발문·본문 문맥에 맞거나 맞지 않는 이유를 설명한다. 학생용에는 유의어·반의어 관계를 알려 주는 표시나 뜻풀이를 넣지 않는다.
- 공통 원고에서는 위 연결을 `questions[].learned_relation_uses`에 `{term_id, choice_number, choice_span:[start,end], surface, reason_ko}`로 기록한다. `term_id`는 담당 공통 단위의 실제 유반 항목 ID, `surface`는 선지의 해당 위치에 실제 등장한 표현이다. 유반이 1세트 이상이면 실제 연결을 최소 1건 기록하고, 보고된 유반 0세트 예외에서만 이 목록을 생략하거나 빈 목록으로 둔다. 존재하지 않는 유반 ID를 기록하지 않는다. 형태 변화와 의미 판단 필요성은 독립 검수자가 대조한다. 연결을 적어 넣었다는 사실만으로 학습 목표 충족을 확정하지 않으며, 세트 전체·9낱말 전체 등의 새 최소 활용 수량을 강제하지 않는다.
- 미니 모의고사의 어휘 문제와 바꿔 쓴 선지에는 FINAL의 유의어·반의어를 우선 활용하되 품사·대상·행위 주체·문맥이 맞아야 한다.
- 정답과 오답의 길이·구체성·문체를 비슷하게 한다. 본문과의 단순 단어 일치, 정답만 긴 설명, 유독 어려운 단어로 정답이 드러나지 않게 한다.
- 반드시·오직·전혀 같은 단정 표현만 보고 상식으로 제거되는 오답을 피한다.
- 오답은 본문과 관련된 범위·부분 정보·주체·시점·인과 등의 오류로 설계한다. 본문에 없는 별개의 이야기는 문항당 하나를 넘기지 않는다.
- 다섯 선지의 사실·문법·자연스러움을 확인한다. 학생 수준에 불필요하게 어려운 표현은 바꾼다.
- 회별·전체 정답 번호 분포를 확인하되 번호 균형을 맞추려고 논리를 훼손하지 않는다.
- 학생용 워크북·문제에는 S/V·끊어읽기·구조 힌트를 미리 표시하지 않는다. 학습 문장이라는 이유로 예외를 만들지 않는다. 출제에 필요한 밑줄·빈칸·번호만 유지한다.

## 6. 제작방 자체검수·동일 DOCX 반영·검수방 인계

이 절과 다음 독립검수의 유반 활용 검사에는 5절의 보고된 0세트 예외를 동일하게 적용한다. 0세트이면 학습 어휘 연결의 부재를 오류로 삼지 않고, 일반 실전문제의 근거·유일정답·영어 선택지·출제 분량·해설을 검수한다.

1. 워크북과 문제 제작이 끝나면 자체검수 1회로 전 문항을 다시 푼다. 원문 근거·유일정답·발문과 선지의 논리·정답 번호와 해설·각 오답 근거·내용 왜곡·선지 문법·어휘 타당성·대상 난도를 확인한다. 공통 단위마다 낱말 뜻·유반 3세트·분석 기본/보충 항목과 연결된 구문 결합 연습·핵심 문장 2개와 답안을 FINAL과 대조하고, 짧은 공통 단위 수량 예외의 원문 근거·실제 제공 수·답안 대응·사용자 보고 여부를 확인한다. 승인 예외 자체를 미해결 누락으로 판정하지 않는다. 낱말 정답표의 번호·뜻 대응, 1·2·3·5번 학생용의 허용되지 않은 힌트 제거와 4번 공식/낱말 뜻 지원·결합 답 비노출, 실전문제 전 영역의 각주 제거와 단순 답안의 불필요한 근거·해설 제거를 확인한다. 교과서 발췌는 SOURCE와 SOURCE_RANGE, 출처 문장 번호·실제 발문에 필요한 연속 범위·동학년 동유형 공식 분량 비교와 짧음 독립 검수·지시 대상·정답과 네 오답 판단의 자족성을 확인한다. 공통 단위·해석지 학습단위·분석단위·워크북과 실전문제 1문항이 1:1로 대응하고, 위 과목별 수량표의 모의 회당 문항 수·3회분·전체 총수가 편성표와 맞는지 확인한다. 문제용 발췌마다 학습단위를 새로 만들지 않았는지 확인한다. 워크북은 해당 공통 단위의 유반 의미를 영어 선택지로 판단하는 유형인지 확인하고, 미니 모의고사 유형 분산과 문항 복제 여부를 점검하되 동일 발췌의 TYPE 반복 자체를 오류로 잡지 않는다.
2. 오답 네 개를 각각 정답 자리에 대입한다. 빈칸은 문법뿐 아니라 의미·논리로 배제한다. 순서·삽입은 다섯 배열/위치를 모두 읽는다. 무관은 나머지 네 문장의 연결 근거도 확인한다.
3. 확정된 오류를 즉시 수정한다. 변경된 선택지·정답·선지 번역·해설·정답표를 함께 맞추고 수정 문항을 원문 전체에 다시 대입한다.
4. references/handoff-format.md대로 [교재명]_UNITXX_문제_QC_HANDOFF.txt 하나에 워크북·문제·정답해설 전체와 낱말 정답표 데이터를 UTF-8로 담는다. 이 TXT에는 로고·쪽 번호·글꼴·색상·여백·장식용 표 디자인·쪽 나눔·장식·반복 학습 안내·조판 정보·검수 내부 메모를 넣지 않는다. 내용 자체검수 후 기존 동일 DOCX의 워크북·문제·정답해설 부분에 추가/교체하고 승인된 서식과 다른 부분은 보존한다. 새로운 DOCX로 전체를 재조판하지 않는다.
5. references/workflow.md에 따라 담당 문제 QC와 같은 DOCX를 사용자가 지정한 현재 교재 폴더에 저장하고 실제 저장본을 다시 확인한다. 클라우드는 연결과 대상 폴더가 확인된 경우에 사용하며, 기존 파일은 지정된 동일 로컬 경로 또는 같은 원격 ID로 갱신한다. 기준 FINAL과 QC·DOCX 저장 대상의 버전 충돌을 확인한다. 지정 원격 저장이 실패하면 workflow.md의 대체 저장·재열람 절차를 따르고 원격 인계 대기로 보고한다.
6. 실제 문제 QC와 DOCX 저장본을 다시 열어 파일명·인코딩·워크북 전체 구성·문항 수·번호·출처·첫 문항·끝 문항·정답·해설·정답표·수정부가 온전하고 실전문제 각주가 없는지 확인한다. DOCX의 기존 해석·분석과 승인 서식이 보존됐는지도 확인한다. 검수방 인계는 두 저장본 확인 후에만 준비 완료로 보고하며 자동 실행으로 표현하지 않는다.
7. 채팅에는 UNIT, 실제 제작 문항 수, 유형별 수, 워크북 포함 여부, 자체검수 완료 여부, 수정 번호, 문제_QC_HANDOFF와 동일 DOCX의 저장·인계 상태·파일명을 간단히 보고하고 DOCX와 별도 검수방용 실행 프롬프트를 제공한다. 전문은 사용자가 특별히 요청할 때만 표시한다.

자체검수는 독립 검수 완료가 아니다. 이 단계에서는 문제_FINAL을 만들지 않으며, 이미 있는 DOCX에 담당 내용을 반영한다. PDF 렌더 및 시각 검수는 내장 MASTER의 layout-rules.md를 따른다. 기존 문제를 재사용할 때도 최신 FINAL과 대조하며 파일명만 바꿔 인계하지 않는다.

## 7. 독립 문제검수와 FINAL 확정

별도 검수방에서 해당 과의 문제 검수를 요청하면 사용자가 지정한 현재 교재 폴더에서 문제_QC_HANDOFF·동일 DOCX·해당 교과서의 해석·분석 FINAL을 찾아 실제 저장본을 읽는다. 권위 원문과 필요한 정답 자료는 사용자가 지정한 원본 위치에서 확인한다. 로컬·클라우드 접근과 지정 원격 파일 접근 실패 처리는 `workflow.md`를 따른다. 기존 문제_FINAL이 있으면 현재 수정 요청과 함께 대조하고 `workflow.md`의 재검수 절차로 기존 수정이 되돌아가지 않게 한다. 문항 수·유형·SOURCE·SOURCE_RANGE는 현재 편성표와 비교한다. 워크북 전체 검수는 필수다. 짧은 공통 단위의 승인 수량 예외는 실제 제공 수와 대응 답안을 검수하며 예외 자체로 FINAL 확정을 보류하지 않는다. 낱말·유의어/반의어 뜻 쓰기·실전문제·핵심 문장 2개 다시 해석과 대응 정답을 모두 검수하며, 필수 구성이나 검수가 빠지면 문제_FINAL을 확정하지 않는다. 필수 파일이 없으면 정확한 파일명과 필요한 선행 단계를 보고한다. 해석·분석 FINAL 없이 문제 FINAL을 확정하지 않는다.

1. 출제에 관여하지 않은 독립 검수자 2명이 각각 전 문항을 푼다. 제작 정답·해설을 먼저 정답으로 가정하지 않고 최초 풀이에서는 가린다. 두 검수자의 실제 분리 여부·전체 검수 범위·풀이 결과·근거·재검증을 기록한다. 실행할 수 없는 환경에서는 미실시로 남기고 제작자의 재풀이를 독립 검수 완료로 바꾸지 않는다.
2. 자체검수 항목 전체와 원문 가공의 복원 가능성을 다시 검증한다. 편성표의 공통 단위별 워크북 1개·실전문제 1문항, 과목별 모의 회당 문항 수·3회분·전체 총수, 워크북의 유반 의미 판단 유형 조건과 미니 모의고사 유형 분포를 확인한다. 같은 발췌의 유형 반복은 허용하되 문항 복제로 수를 채우지 않았는지 확인한다. 사용자 지정 예외가 있으면 그 실제 수량·배분과 대조한다. 정답 일치만으로 통과시키지 않고 네 오답 각각의 배제 근거를 확인한다. 워크북 다섯 단계의 순서·공통 단위별 유반 3세트와 분석 항목별 구문 연습·핵심 문장 2개(짧은 공통 단위의 보고된 예외는 실제 수)·정답 누락·일반 숫자 번호 대응, 1·2·3·5번 학생용의 허용되지 않은 힌트 제거와 4번 공식/낱말 뜻 지원·결합 답 비노출, 간단 답안과 실전문제 상세 해설의 구분, FINAL과의 일치 및 교과서 발췌 조건도 확인한다.
3. 확정 오류는 검수팀이 즉시 수정한다. 정상 문항을 취향에 맞게 바꾸지 않는다. 해석·분석 FINAL의 핵심 문장·유반 세트·해석이 변경됐으면 관련 워크북·답안·선지·근거도 대조한다. 수정한 문항과 연결된 정답·근거·해설·번역·정답표를 다시 검증한다.
4. 미해결 복수정답이나 근거 충돌이 있으면 문제_FINAL을 확정하지 않는다. 해결된 문항만으로 전체 검수가 끝났다고 보고하지 않는다.
5. 워크북과 전 문항 검수·수정부 재검증이 끝나면 오류 0건인 경우도 전체 내용을 [교재명]_UNITXX_문제_FINAL.txt로 저장한다. 확정 수정은 같은 DOCX의 대응 부분에 직접 반영하고 다른 부분과 승인 서식을 보존한다. 사용자 지정 교재 폴더에 저장하고 실제 저장본을 재확인한다. 로컬·클라우드 저장과 지정 원격 저장 실패 시 대체 보관은 references/workflow.md를 따른다. 변경 이력·내부 메모는 넣지 않는다.
6. 사용자가 지정한 교재 폴더의 문제_FINAL과 동일 DOCX 저장본을 다시 읽고 워크북 전체·문항 수·정답·수정부·끝부분 및 상호 일치를 확인한 뒤에만 인계 완료를 보고한다. 지정한 로컬 폴더에서 작업하는 경우 로컬 저장본 재열람으로 저장 확인을 마친다. 지정 원격 저장이 실패해 대체 저장만 성공했다면 내용 검수 완료와 원격 인계 대기를 구분한다. 제작방의 5번 정리는 최신 FINAL과 이 동일 DOCX에서 이어 한다. 검수한 DOCX와 제작방용 실행 프롬프트를 함께 제공한다.

별도 검수팀을 운영하는 프로젝트에서는 제작팀의 추가 자체 점검을 독립 문제검수팀의 완료로 대체하지 않는다. 실제 수행한 검수 범위와 분리 여부를 정확히 보고한다.


## DOCX 출력 번호와 MASTER 조판

Q01 등은 원고 전체에서 유일한 내부 ID다. 학생용 출력 번호와 구별하며, 워크북 실전문제와 미니 모의고사 번호를 분리하고 미니 모의고사는 각 회차마다 1번부터 시작한다. 정답표와 해설도 회차+회차 내 번호로 일치시킨다. 각주의 필수 낱말 별표는 확정 오늘의 낱말 목록과 연결한다. 글자 크기·간격·표·답안 공간·페이지 흐름·렌더 검수는 `layout-rules.md`를 필수 적용한다.


## 통합 세부 원칙

- 미니 모의고사 정답의 본문 낱말을 모두 유의어로 교체하지 않는다. 문맥상 필요한 원어는 허용하며 단순 낱말 일치·길이·문체 차이로 정답이 노출되지 않는지 확인한다. 빈칸 정답의 문맥상 유의 표현 규칙은 유지한다.
- 순서 문제는 원문 단락이 3개 이상이라는 하한을 두지 않는다. 주어진 글과 A/B/C가 의미 있는 범위이고 정답 배열로 원문이 복원되며, 모든 대안 배열을 배제할 수 있을 때만 출제한다. 원문을 억지로 쪼개거나 새 문장으로 연결하지 않는다.
- 글 뒤에서 앞 논지를 수정·뒤집으면 그 전환을 포함한 제시 범위 전체의 논지에 맞게 정답을 만든다. 정답을 유지하려고 반전 앞에서 자동으로 자르지 않는다. 실제 제시 범위 전체의 논지·연속 발췌·동학년 동유형 모의고사 분량 비교·범위 안 근거 자족성을 함께 지킨다.
- 순서·삽입에서는 대명사·지시어·정관사 명사구의 실제 선행 대상과 사건 순서를 비교한다. 특정 연결어 하나로 유일성을 단정하지 않는다. 주어진 글의 범위나 분할 위치를 바꾸었으면 모든 대안과 원문 복원을 다시 확인한다.
- 정답과 네 오답은 비교 가능한 문장 틀·문체를 유지하고 어색한 연어로 정오가 드러나지 않게 한다. 문맥상 올바른 다양한 표현을 전부 같은 명사로 강제하지 않는다.
- 전체 교재의 객관식 정답에서 한 번호가 70% 이상을 차지하지 않게 한다. 번호 변경 시 선지·정답·선지 번역·오답 해설·빠른 정답표를 함께 갱신하고 내용 논리를 훼손하지 않는다. 사용자 지정 부분 제작은 전체 편성표와 대조하고 미확정 전체 분포를 검증했다고 보고하지 않는다.
- 일반 문제는 필요한 가공 지문을 각각 제공한다. 매회 마지막의 확정 공유 장문 두 문항만 passage_group 계약에 따라 지문을 한 번 싣고 두 문항을 연결한다. 다른 승인 문항을 임의로 묶거나 번호를 재배치하지 않는다. 주어진 문장과 주어진 글은 지문 앞의 대응 박스 역할로 구별한다.
- 기호형 문항도 유형별 필수 구성을 끝까지 검사하며 빈 문항은 통과시키지 않는다. 필요한 선지 번역과 빠른 정답표의 실제 대응도 검사한다. 기계 검수와 사람의 의미 검수·독립 풀이를 구분한다.


## 최신 문제 조판과 저장본 검수

- 일반 지문 한 문단·내부 수동 줄바꿈 없음, 순서 A/B/C 및 주어진 글 박스 예외, 공유 장문 단락 유지, 두 문항 공유 지문 1회 출력 여부를 실제 저장 DOCX에서 검사한다. 원문 자체의 문단 경계나 추적 위치를 삭제하지 않는다.
- 문제 사이에는 승인 MASTER의 빈 줄 두 개에 해당하는 고정 세로 간격을 둔다. 한 쪽 두 문제 정도의 여유를 목표로 하며 긴 문제나 장문 세트는 한 쪽을 사용할 수 있다. 문제 수를 맞추려고 글자 크기·줄 간격을 줄이지 않는다. 페이지 끝에서 발문만 남거나 선택지 일부만 다음 쪽으로 밀리지 않게 실제 Word 출력으로 확인한다.
- 순서 선택지 ACB/BAC/BCA/CAB/CBA, 내용 일치·불일치의 표준 발문, 문맥 어휘의 다섯 표적 밑줄, 함축 의미의 본문·발문 표적 밑줄, 각 회차 마지막 두 문항과 빠른 정답·해설의 대응을 전수 확인한다.
- 공식 분량 표본과 단어 수 비교가 통과해도 교육적 분량·문항 타당성·유일정답·독립 검수 완료를 뜻하지 않는다. 짧음으로 표시된 문항은 실제 독립 검수 기록 없이는 최종 확정하지 않는다.

### 정답 근거 제목과 공유 장문 배치

`정답 근거`를 별도 제목으로 표시하고 `선지 해석`·`오답 정리`와 같은 제목 서식을 적용한다. 실제 근거와 설명 문구는 다음 본문에 보존한다. 사용자 승인에 따라 독립 제목 줄로 인한 해설 페이지 증가는 허용하며 본문 축소나 제목을 같은 줄로 합치는 방법으로 되돌리지 않는다. 공유 장문 앞에 무조건 새 쪽을 넣지 않는다. 앞 문제와 함께 기존 서식·문항 간격으로 들어가면 같은 페이지에 배치하고, 제목 고립·선지 분리·큰 빈 공간은 실제 Word로 확인한다. 페이지당 문항 수만으로 강제 쪽 나눔을 만들지 않는다.
