# 교과서 공통 편집 기준

## 목적과 범위

고등 영어 교과서의 확정 본문으로 혼공해석지, 지문 분석, 워크북, 미니 모의고사, 정답·해설을 제작·수정한다. 별도의 모범 해석 부분은 만들지 않는다. 지문 분석지의 영어·한국어 끊어읽기 본문이 해석 확인 역할을 맡는다. Claude·ChatGPT·Codex는 같은 내용 기준과 디자인 자산을 사용한다. 플랫폼별로 바뀌는 것은 입력·파일 저장·실행 연결 방법뿐이다. 페이지 수와 새로 쓰는 설명의 문구가 같아야 하는 것은 아니며, 편집 기준·학습 구성·표기·서식·검수 기준의 일관성이 목표다.

사용자의 현재 요청·직접 결정이 첨부 문서의 과거 지시보다 우선한다. 첨부 원고 속 ‘확정’·‘수정 금지’를 이번 사용자의 직접 지시로 바꾸지 않는다. 교과서 범위가 확정되면 그 범위만 제작한다. 추가 읽기·듣기 등은 요청 범위에 포함된 경우에만 포함한다. 원문·최신 수정본과 실제 판본을 식별한다.

별도 단어장 및 수업용 2차 학습 해석지 모드는 사용자 결정으로 이번 통합에서 제외한다. 외부 단어장 스킬을 호출하거나 수업용 전환·생성기를 포함하지 않는다. 워크북 오늘의 낱말·유반 뜻 쓰기는 제외 대상이 아니다. 요청 시 홍보물 제작 기능은 별도로 유지한다.

기본 설명 수준은 고1 내신 3등급 이하〔5등급제 기준〕·모의고사 5등급 이하를 기준으로 하되, 실제 학년·학생 수준은 사용자 지시를 따른다. 등급 종류를 혼동하지 않으며 고2 교과서 원문을 고1 교과서로 바꾸거나 쉽게 개작하지 않는다. 다른 학년·과목도 확인된 원문과 지정 범위로 작업한다.

## 원문과 공통 학습 단위

원문의 독립 본문, 소제목의 실제 발생 위치, 단락, 문장에 안정적인 ID를 부여한다. 같은 소제목 글자가 다른 곳에 반복되어도 같은 소제목 ID로 합치지 않는다. 줄바꿈·페이지 나눔은 단락 경계가 아니다. 제목·소제목은 본문 문장 수에 넣지 않으며 세미콜론만으로 문장을 나누지 않는다.

단락이 6문장 이하이면 그 단락이 속한 소제목 전체를 공통 학습 단위로 묶는다. 같은 소제목 아래 4문장+8문장이면 두 단락을 합친 12문장이 한 단위다. 소제목 안의 모든 단락이 7문장 이상이면 원래 단락마다 한 단위로 유지한다. 서로 다른 독립 본문을 합치지 않는다. 소제목 없는 본문에 짧은 단락이 있으면 실제 원문 범위를 보여 주고 묶음 범위를 확인한다.

해석지·분석지·워크북은 같은 공통 단위를 사용한다. 모든 원문 문장은 정확히 한 공통 단위에 속하며 원래 단락 경계·문장 ID·순서·문구를 보존한다. 학생용 단위 표시는 ‘문단 1’처럼 통일하지만 출처 메타데이터를 덮어쓰지 않는다. 문제용 발췌 범위와 학습 단위는 별개다.

단위마다 핵심 문장 기본 2개, 구문으로 해석하기 기본 3개와 승인된 결합 공식 보충, 내용 이해를 돕는 3문장의 쉬운 풀이, 유의어·반의어 기본 3세트를 연결한다. 어법은 항목마다 학습 초점 하나에 제목·인용·설명을 맞추고, 구문 공식·문맥 뜻에 각 자리의 실제 원문과 뜻을 대입한 뒤 핵심 결합 해석을 보여 준다. 품사·명칭·공식이나 시험 판별 요령만 소개하거나 원문 전체·번역·추상적 읽기 조언으로 대입을 대신하지 않는다. 이 기준으로 별도 구조 힌트의 짧은 표시를 늘리지 않는다. 수동·능동 완료의 기능/낱말 결합은 상위 구조 힌트를 교체하지 않는다. 해당 문장에서 결합 힌트로 선정되지 않은 공식은 같은 단위의 ‘구문으로 해석하기’ 대표 사례에 연결한다. 기존 기본 분석 3개를 유지하고, 그 3개에서 아직 설명하지 않은 결합 공식만 대표 사례를 보충한다. 같은 단위·같은 공식의 보충 설명은 한 번만 둔다. 다른 문장에 같은 공식의 힌트가 있다는 이유로 해당 문장의 분석 연결을 생략하지 않으며, 기존 분석이 그 공식을 설명하면 그 항목에 연결하고 추가하지 않는다. 부분 부정처럼 해당 구절을 단순 기능 공식으로 연습하면 뜻이 바뀌는 경우에는 사용자에게 실제 예를 제시하고 승인받은 경우만 명시적 예외로 연결한다. 승인된 부분 부정 분석·연습은 유지하고 같은 단위의 다른 문장으로 수동 결합을 연습한다. 예외 범위·승인 근거·원래 항목과 대체 항목을 기록하며 부분 부정을 일반 부정으로 고치거나 임의 면제하지 않는다. 완료진행 등 이번 수동/능동 완료 구별 밖의 정책을 새로 확대하지 않는다. 분석의 기본 항목과 승인된 보충 항목을 모두 같은 순서의 워크북 ‘4. 구문 결합해서 해석하기’에 1:1로 연결한다. 학생용은 번호가 붙은 영어 구절·해석 빈칸을 먼저 두고, 바로 아래 도움말에 배운 주초점 공식·문맥 뜻 → 실제 연습 범위의 필요한 보조 기능·낱말 뜻 순서로 제공한다. 보조 기능은 같은 문장의 기존 각주 ID로 연결하며 학습 초점 자체를 바꾸지 않는다. 결합된 한국어 답은 정답지에만 둔다. 공식과 낱말 뜻은 기존 승인 내용과 일치시키며 원문 전체를 반복 해석하는 활동으로 늘리지 않는다. 동사 구문의 불필요한 A/B 풀이를 빼거나 묶음 각주의 실제 연습 낱말만 지원할 때는 manuscript-data.md의 검토된 support_overrides를 적용한다. 쉬운 풀이는 기존처럼 단위당 원문 3문장을 골라 원문 순서로 설명하며 표시명은 ‘각 문장 쉬운 풀이’다. 선정 문장의 앞 문맥과 글 속 역할을 중학생 눈높이로 연결하고, 설명문은 한 문장에 한 내용을 담되 문장 수는 제한하지 않는다. 문법 분석·번역 반복이나 추측한 배경 사실로 대신하지 않는다. 문체·예시·검수는 [전용 기준](analysis-content.md#각-문장-쉬운-풀이)을 따른다. 소제목 전체도 3문장 미만이면 실제 문장 수와 문법 근거만 사용하고 기준수·실제수·사유를 보고한다. 원문 밖 문장·문법 근거·어휘 관계를 창작하거나 중복하여 수를 채우지 않는다.

## 해석·S/V·각주·구조 힌트

분석지 본문에 공통 학습 단위의 모든 문장을 원문 순서대로 제공한다. 각 문장의 출력 순서는 영어 끊어읽기 → 대응 한국어 끊어읽기 → 자연 해석이다. 한국어 끊어읽기가 직역의 역할을 맡으며 별도의 문장 단위 직역 줄은 출력하지 않는다. 자연 해석은 필수인 별도 필드이며 청크를 이어 붙여 대신하지 않는다. 별도 모범 해석 부분을 없앤다는 이유로 일부 문장의 대응 해석을 누락하지 않는다. 영어·한국어 끊어읽기는 같은 조각 수로 대응하며 영어 조각을 다시 붙이면 원문이 보존되어야 한다. 주체·시제·부정·양태·수치·지시 대상은 모든 자료에서 일치시킨다. U34·U36이 앞선 U21의 별도 모범 해석 및 직역 줄 구성을 대체한다.

S/V는 한 절 안에서 `S: …, V: …`, 절 사이에서 `／`를 사용한다. 종속절은 S′·V′로 적고 중첩 깊이에 따라 프라임을 늘리지 않는다. 절을 이끄는 말은 대괄호로 표시하고, 이끄는 말이 없는 주절은 `[주절]` 없이 `S: …, V: …`로 시작한다. 원문 절 순서를 유지한다. 주격 관계대명사절은 관계대명사 뒤에 별도 주어가 명시되지 않으므로 `[who] V′: …`처럼 V′만 표시하고 S′를 붙이지 않는다. 목적격 관계대명사절은 실제 주어·동사를 S′·V′로 표시한다. 이 규칙은 관계절에 문법적 주어가 없다는 뜻이 아니다. 동사 칸에는 실제 동사구만 넣고 목적어·보어·부사는 넣지 않는다.

주어의 내부 문법 판정은 완전한 명사구를 보존한다. 긴 명사구 주어의 S/V 표시에서는 한정사·앞수식어·중심명사를 남기고 뒤수식어를 제외한다. 내부 `subject_spans`의 실제 전체 주어는 보존하며, 문법 검토 후 `subject_display_spans`와 `subject_display_review`로 표시 범위와 이유를 따로 기록한다. 명사절·동명사 주어, 부분/수량 표현, 등위 주어는 이 명사구 축약으로 의미·수·구조를 잃지 않게 전체를 유지한다. 다만 `All you need is love.` 같은 All+생략 목적격 관계절 구조는 주절 S=All, V=is로 적고 관계절 S′=you, V′=need를 따로 제공한다. All 예외와 검토된 명사구 표시 축약을 구별하며, 내부 전체 주어를 수식어 없는 범위로 덮어쓰지 않는다. 해당 all의 문맥 뜻도 각주에 제공한다.

명령문에서 주어가 생략되어 있으면 `(You)`를 덧붙이지 않고 `V: Open`처럼 동사만 표시한다. 실제 주어가 명시된 명령문의 주어까지 지우지 않는다. S/V의 대명사에는 `(= Scientists)` 같은 지시 대상을 덧붙이지 않고 원문 대명사만 적는다. 지시 대상 지원은 각주 규칙에 따른다.

각주는 혼공해석지 전용이다. 전치사+관계대명사 각주는 `전치사 + 관계대명사 S′ V′ — S′(이/가) V′하는`으로 통일한다. 실제 문맥에서 이 틀을 적용하면 뜻·시제·관계가 손상되는 예는 강제로 고치지 않고 `reading_checks.review_record`에 원문·문장/각주 ID·적용 불가 이유·문맥상 뜻을 남겨 1차 L 독립 검수 때 사용자에게 보고한다. 일반 전치사·간접의문문·그 밖의 관계사에 이 통일 기준을 확대하지 않는다. 일반 단어·숙어·기능 표현은 문장마다 반복 제공하고 원문 등장 위치 순서로 배열한다. 고유명사는 지문 첫 등장에 제공한다. 단독 you는 각주에서 제외하며 원문·S/V는 보존한다. 대명사 they·their·them·themselves·our·us·his·hers·its는 문장마다 뜻+실제 지시 대상을 괄호로 적는다. 대상은 앞 문맥에서 확인하며 추측하지 않는다. 한국어 뜻은 `we — 우리는`, `they — 그들은/그것들은`, `us — 우리를/우리에게`처럼 문장 또는 구문 틀의 실제 격에 맞춘다. A가 틀에 들어가는 us는 ‘우리가’처럼 대응시키며 소유격의 소유 관계는 유지한다. 이 목록 밖의 모든 대명사를 일괄 필수로 확대하지 않는다.

다의어의 본문 뜻이 흔한 뜻과 다르면 본문 뜻을 먼저, 흔한 뜻을 뒤에 함께 제공한다. 예: `respect — 측면 (흔한 뜻: 존경)`. 두 뜻이 같으면 하나만 적으며 실제 존재하는 뜻인지 확인한다. 흔한 뜻을 알려 주기 위해 문맥 뜻을 바꾸거나 필요한 전치사 결합을 임의로 쪼개지 않는다.

수동·능동 완료는 기능 공식과 낱말을 나눈다. 수동의 낱말은 실제 p.p.형·수동 뜻(`be p.p. — ~되다 / produced — 생산된`), 능동 완료는 원형·기본 뜻과 실제 p.p. 관계(`have p.p. — ~했다 / find — 발견하다 (found는 find의 p.p.형)`)로 제공한다. 완료수동 `have been p.p.`는 수동이므로 실제 p.p.형을 유지한다. 전치사의 흔한 뜻으로 이해하기 어려운 `be provided with`·`be satisfied with` 등의 숙어는 한 각주로 유지한다. 독립 p.p.는 실제 형태·문맥 뜻(`held — 개최된`, `trained — 훈련받은`), 일반 정규과거 -ed는 원형·기본 뜻, 불규칙 과거는 현행 표기, 일반 -ing는 기존 기능/원형 분리를 유지한다. 이번 p.p. 구별 밖인 완료진행 `have been V-ing`와 오늘의 낱말 선정·표기는 별도 현행 규칙을 유지한다. 동사의 뜻을 완성하는 to V는 `decide to V — ~하기로 결심하다`, `struggle to V — ~하려고 애쓰다`처럼 동사 구문으로 묶고 V의 실제 낱말 뜻은 별도로 지원한다. 별도 목적이면 `use — 사용하다 / to V — ~하기 위해 / buy — 사다`로 나눈다. `had struggled to enter`는 `had p.p. — ~했다 / struggle to V — ~하려고 애쓰다 (struggled는 struggle의 p.p.형) / enter — 들어가다`다. 단독 to V에 `~하기로·~하려고·~하는 데`를 붙이지 않으며 문맥상 보충/목적이 불명확하면 실제 예와 추천안을 보고하고 답을 기다린다. 표제어의 정규화는 원문·청크·S/V·위치 연결을 바꾸지 않는다. 결합 항목과 별도 기능을 중복하지 않고 필요한 목적어 낱말 뜻은 별도로 둔다.

be 고정 숙어는 예외로 실제 be가 있을 때 `be about to V — 막 ~하려 하다`처럼 be 원형·패턴을 표제어로 쓴다. be 없는 분사·형용사나 become/get/seem 뒤 표현에 be를 추가하지 않는다. 원문의 영어는 바꾸지 않는다.

3인칭 단수 일반동사 각주 표제어는 `helps → help`처럼 원형으로 제공하고, 명사 복수형은 `creatures`처럼 보존한다. 기존 숙어·구문 묶음과 기능 공식은 유지한다. 원문·S/V·힌트·실제 연습 영어·오늘의 낱말은 그대로이며 같은 각주 ID를 재사용하는 도움말에만 같은 표제어를 적용한다. 품사·원형의 의미 검토와 선언 범위는 [각주 활용형 기준](gloss-rules.md#실제-형태와-활용형)을 따른다.

전치사는 각 위치의 실제 품사와 뜻을 확인한다. 수량·종류+of가 뒤 명사 앞에서 같은 어순의 `~의`로 대응하면 `metric tons of — (미터법) 톤의`처럼 한 각주로 묶고 내부를 끊지 않는다. 일반 후치수식 전체로 확대하지 않는다. 이 승인 예외 이외에는 대표 뜻으로 이해되면 단어와 분리하고, 그렇지 않으면 필요한 최소 결합으로 설명한다. `in 11 days`는 문맥에 따라 ‘11일 만에’ 또는 ‘11일 후에’로 묶는다. 다른 위치의 같은 전치사를 숙어에 포함됐다는 이유로 누락하지 않는다. 각주 분리가 모든 전치사 앞의 끊어읽기를 강제하는 것은 아니다. **명사를 후치수식하는 형용사구·전치사구는 각각 시작 앞에서 반드시 끊는다.** 수동태에서 ‘누가·무엇에 의해’를 나타내는 by 구도 by 앞에서 끊는다. 세부 용법 구분과 부분 부정 보존은 `analysis-content.md`를 따른다. 형용사구 내부 보충 전치사구나 고정 숙어까지 다시 자르지 않는다: `a book / full of pictures`, `the people / in the room`.

각주는 뜻을 먼저 쓰고 허용된 짧은 문법 이름표를 뒤에 붙일 수 있다. 이름표만 있는 항목은 금지한다. 상세 허용·금지표와 연결어 템플릿은 전수 대조 후 별도 참조에 연결한다. 각주의 이름표 제한을 S/V·힌트·분석의 어법 설명에 확대하지 않는다.

일반 구조 힌트는 `영어 → 한국어 해석 (structure_label)` 한 줄에서 대응 부분을 같은 대괄호로 묶고 한국어 어순에 맞게 붙여 읽는 자리를 보여 준다. 예: `The protein [containing copper] → [구리를 포함한] 단백질 (현재분사 후치수식)`. 접속사·명사절·간접의문문·관계절의 연결 힌트는 연결어와 실제 S′·V′까지만 표시하고 동사 뒤 목적어·전치사 대상은 번역하지 않는다. 주격 관계사는 V′만, be동사는 최소 보어만 예외로 남긴다. 관계사의 앞 명사와 가주어 It~that 틀은 보존하되 일반 명사절 바깥의 means·have found는 표시하지 않는다. 표시한 주어·동사 안의 시제·부정·양태를 유지한다. 힌트 하나는 문법 연결 한 가지에 집중한다. `throw away`·`feed on`처럼 그 자체 뜻을 익히는 숙어는 각주로 제공하며 그것만으로 구조 힌트 후보가 되지 않는다. `provide A with B`·`help A V`·`allow A to V`처럼 뒤의 대상·동사·준동사를 연결해 해석하는 동사 구문만 후순위 후보로 삼는다. 전치사나 불변화사가 붙었다는 이유만으로 모든 구동사를 후보로 삼지 않는다. 상위 after·that 힌트에서 동사 뜻을 보존하는 `throw … away`·`feed on` 범위는 그대로 유지한다. 관계사·접속사·명사절·준동사 수식 등 문법 연결을 먼저 고르고, stop A from V-ing·help A V·allow A to V·keep A B 같은 동사 구문과 기능·낱말 결합은 후순위로 둔다. 상위 문법을 보여 주면서 안쪽 동사 구문의 A/B와 완성 해석까지 함께 넣지 않는다. 동명사·분사·부정사 자체의 한 연결에 필요한 성분은 일괄 삭제하지 않으며, 실제 연속 발췌·생략 관계사/접속사 괄호 표시·분리 구동사 목적어 생략 예외는 `analysis-content.md`를 따른다. 생략 관계사는 힌트에만 `[(that) …]`처럼 실제 문법에 맞는 표지를 보충하고 관계사 글자와 한국어의 최소 대응 부분을 대응 강조한다. 표지 괄호는 보통 글씨로 두고 원문·다른 자료는 그대로 유지하며 생략 명사절 접속사 that은 관계사와 구별해 `display_mode:omitted-conjunction`, `omitted_conjunction:that`을 사용한다. 힌트에만 `[(that) laws had to be changed] → [법이 바뀌어야 한다고] (명사절 접속사 that 생략)`처럼 표시하고, 괄호는 보통·that 글자와 실제 S′의 이/가 및 연결 어미는 굵게+밑줄로 대응한다. 생략 관계사는 기존 `omitted-relative`를 유지한다. 두 유형 모두 빈 대응 링크로 대체하지 않고 원문·청크·S/V·각주·자연 해석에 보충 표지를 추가하지 않는다. 생략된 주어·to까지 이 예외를 확대하지 않는다. 한국어 뒤의 짧은 구조 이름표는 한 번만 붙이며 긴 설명문이나 읽기 지시는 덧붙이지 않는다. 짝 구조(`paired-structure`)는 원문에서 고른 대응 조각을 ` … `로 연결한 영어와 그 부분만 옮긴 한국어를 한 줄에 쓴다. `both to hide … and to secretly crawl up to … → 숨기 위해서도 … 몰래 기어서 다가가기 위해서도 …`처럼 문장 전체를 번역하지 않으며 별도 이름표·설명문을 붙이지 않는다. 생략된 관계사·that 및 가주어 등의 선정 우선순위, 문장당 최대 2개, 포함 힌트 합치기를 유지한다. 명시된 관계대명사·관계부사도 실제 관계절이면 최소 연결을 힌트에 포함하며, 각주·S/V만으로 충분하다고 빼지 않는다. 이미 포함된 같은 관계는 중복하지 않는다. 짝 구조는 기능·낱말 결합보다 먼저 검토한다. 구조 힌트가 비어 있고 상위 문법·짝 구조·필요한 동사 구문 후보가 없으면 실제 수동태를 후순위로 제공한다. `produced(생산된) → is produced(생산된다) (be p.p.)`처럼 낱말 뜻과 동사 부분만 표시하며 실제 태·시제·부정·양태를 보존한다. 수동·능동 완료의 기능 결합 힌트는 `category:function-combination`, `display_mode:verb-function`에 `lexical_step`을 연결하여 `produced(생산된) → is produced(생산된다) (be p.p.)`, `find(발견하다) → have found(발견했다) (have p.p.)`처럼 한 줄로 표시한다. 왼쪽 낱말 뜻과 오른쪽 실제 동사구 결합 뜻을 구별하며 수동 뜻을 두 번 더하지 않는다. 실제 시제·태·부정·양태와 표시 범위 안의 부사는 보존하고 주어·목적어·A/B 틀·by/for 구는 덧붙이지 않는다. 공식 `formula_label`과 낱말 뜻 괄호는 보통 글씨다. 일반 진행·완료진행 등 이번 p.p. 구별 밖의 기존 힌트와 `what to V + do → 무엇을 해야 할지`는 현행 형식을 유지한다. 짝 구조와 기능 결합의 `display_pairs`는 각각 정확히 1개이며 승인된 lexical_step 외 여러 단계 풀이·추가 구조 이름표를 넣지 않는다. 시제태의 보통 괄호 공식은 `formula_label`로만 붙인다. 모든 유형은 수동 줄바꿈 없이 작성하며 Word의 자연스러운 줄 감김을 허용한다. 상세 내부 판정은 보존하되 학생용에 출력하지 않는다. 한국어 힌트는 문법 기능이 보이는 직역을 우선한다. 영어·한국어 모두 보통 글씨를 기본으로 하고, 선택한 한 문법의 실제 대응과 명시된 S′/A 주어 조사 이/가를 `emphasis_links`로 연결한다. 일반 문법은 양쪽 굵게+한 줄 밑줄, `emphasis_policy:ko-only-verb-construction`인 동사 결합은 영어 보통·한국어 조사·연결 어미만 강조로 표시한다. 영어의 기존 색·한국어 검정·대괄호·7.5pt·문단 간격은 유지한다. 대괄호 전체나 문법 대응과 무관한 한국어 조사를 강조하지 않는다. 독립 p.p. 각주에 연결한 힌트는 held↔개최된 전체 대응을 적용하며 by/without V-ing에 확대하지 않는다. 세부 작성·검수는 `analysis-content.md`의 구조 힌트를 따른다.

문맥상 가주어 It과 that 진주어로 확인한 구문은 전체 `It … that S′ V′` 틀과 뜻을 한 각주로 제공하고 같은 위치의 It·that을 따로 나누어 제공하지 않는다. `It seems that`·`It appears that`·`It is likely that`는 예시이며 특정 동사만 허용하는 제한이 아니다. 본문 끊어읽기에서도 It부터 that까지는 끊지 않는다. that절 내부의 필요한 후치수식 경계와 낱말 각주는 유지한다. to 진주어 등 다른 가주어는 실제 진주어 연결을 짧게 안내한다. 실제 대상을 가리키는 it·가목적어·강조구문을 가주어로 오인하지 않는다.

가주어 뒤의 진주어 to부정사는 앞에서 끊는다. 예: `It is important / to study hard.`. 가주어 It+that절의 예외를 to 진주어 구조에 확대하거나 문장 전체를 하나의 청크로 강제하지 않는다. 고정 숙어·구동사를 나누지 않는 일반 규칙은 별도로 유지한다.

상관어구는 두 부분이 멀리 떨어져 있어도 A·B를 포함한 하나의 구문 틀로 각주에 제공한다. 예: `not only A but also B — A뿐 아니라 B도`, `either A or B — A 또는 B 중 하나`. A·B 안의 필요한 낱말 뜻은 따로 제공한다. 이 원칙은 각주의 관계 설명이며 상관어구 사이의 긴 구간 전체를 하나의 끊어읽기 청크로 강제하지 않는다.

## 분석·워크북·문항

끊어읽기 청크가 8낱말을 넘으면 의미·문법 경계를 재검토한다. 적절한 경계가 없으면 유지하며 수량을 맞추는 억지 분할은 금지한다. 청크 길이의 하한은 두지 않는다(U49).

공통 단위의 제목 또는 주제 하나를 골라 영어(한국어) 한 줄로 해석지와 워크북에 표시한다(A08). 분석지에는 이 작성 제목을 중복 배치하지 않는다. 제목/주제 종류는 원고·인계·계획에서 보존한다. 원문 소제목은 원문 그대로 해석지에 별도 보존한다. 의도·흐름·각 문장 쉬운 풀이·어법·유반은 분석지에 단위마다 제공한다.

분석지에는 일반 ‘단어 및 숙어 리스트’ 표를 추가하지 않는다(U50). 필수 유의어·반의어는 유지한다. 별도 단어장 제외 U46과 각각 기록한다.

워크북은 오늘의 낱말 → 유의어·반의어 뜻 쓰기 → 실전문제 1문항 → 구문 결합해서 해석하기 → 핵심 문장 다시 해석하기 순서다. 기존 1. 오늘의 낱말 → 2. 유의어·반의어 뜻 쓰기 → 3. 실전문제를 유지하고 새 쪽에서 4. 구문 결합해서 해석하기 → 5. 핵심 문장 N개 다시 해석하기 순서로 이어 간다. 5번만 다시 강제 새 쪽으로 보내지 않으며 핵심 문장 제목·전체 활동을 함께 배치한다. 정답도 같은 4·5번에 연결하고 유반 0세트는 빈 2번만 생략하여 1·3·4·5를 유지한다. 오늘의 낱말은 최대 8개이며 핵심성·다의어 함정을 우선 고려한다. 확정 목록에 대응하는 각주에 ★를 붙이고 같은 단위의 반복 출현에도 표시한다. 문장별 절반 상한은 두지 않는다. 아직 목록이 없으면 별표를 임의로 선정하지 않는다.

워크북 핵심 문장 활동에는 영어 원문과 해석 발문·필기 공간만 제공한다. 학생이 직접 끊어읽기나 S/V를 표시하는 별도 활동은 넣지 않는다. 해석지의 S/V·끊어읽기 지원을 없애는 규칙은 아니다.

유반 활동은 확정 세트의 개별 어휘를 섞어 뜻을 쓰게 한다. 관계 라벨·화살표·등호·세트 묶음을 숨긴다. 유반이 있는 단위의 워크북 실전문제는 학습한 유반의 의미를 영어 선지로 판단해야 풀리는 유형으로 제한한다. 배운 어휘는 정답·오답 모두에 활용하되 유의어=정답·반의어=오답이나 그 반대 역할을 고정하지 않는다. 원문 근거 부족을 보고한 유반 0세트 단위는 일반 실전문제로 출제하며, 유반이나 오늘의 낱말 연결을 억지로 요구하지 않는다. 순서·삽입·본문 번호형 어휘 등은 미니 모의고사에 배정한다.

어법 문항은 제외한다. 같은 발췌·지문·회차 사이 유형 반복은 허용하되 문제 복제는 금지한다. 문장형 선지는 영어로, 한국어 해석은 해설에만 둔다. 기호가 선지인 유형은 그 기호를 유지하고 목록을 중복 출력하지 않는다.

미니 모의고사 정답의 본문 낱말을 모두 유의어로 교체하지 않는다. 문맥상 필요한 원어는 허용하되 단순 낱말 일치로 답이 드러나지 않게 한다. 순서 문제는 원문 단락 3개 이상이라는 하한 없이 의미 있는 A/B/C 구성·원문 복원·유일정답을 확인한다. 주제·요지 문제는 제시 범위 전체의 논지에 정답을 맞추며 정답을 살리려고 반전 앞에서 자동으로 자르지 않는다.

미니 모의고사는 공통영어1·2에서 5문항×3회, 영어II에서 7문항×3회다. 워크북 문항은 별도이며 학습 단위 수가 L이면 전체 객관식은 각각 L+15, L+21이다. 본문 표시 명칭은 ‘미니 모의고사’를 유지하며 최신 최종 출고의 분권 파일명은 `_04_실전모의.docx`다. 내부 Q ID는 전체에서 유일하게 유지하고 학생용 번호는 워크북과 모의를 구분하여 모의 각 회차 1번부터 매긴다. 정답표·해설도 같은 매핑을 사용한다.

## 공통 조판·수정·검수

공통 승인 MASTER 자산을 사용한다. A4, 사방 여백 12.7mm, footer 6.35mm, 본문 하단 12.7mm를 유지한다. S/V 7.5pt, 각주 및 그 ★ 8.5pt, 구조 힌트 7.5pt, 핵심 영어·문제 영어 10pt다. 글꼴·색·역할별 간격·표·브랜드·표지는 공통 MASTER와 승인된 파생 역할에 따른다. 구조 힌트 한국어의 검정 기본·조사/어미 강조는 그 범위에만 적용하는 파생 서식이다. 각주 ★는 남색 굵게, 핵심 문장 ★는 주황색으로 구분한다.

삽입·순서의 주어진 문장/글은 본문 앞 박스에 둔다. 클로드의 0.75pt 파란 테두리·5pt 여유와 GPT 문제 본문 서식을 결합한 공통 규격을 사용한다(U51). 세부 수치는 `layout-rules.md`에 고정한다.

워크북은 지정 서식과 필기 공간으로 한 쪽에 들어가면 한 쪽, 넘치면 자연스럽게 이어간다. 쪽수를 맞추기 위해 글자·간격·답안 공간을 줄이지 않는다. 공통 단위의 순서는 혼공해석지 → 지문 분석(끊어읽기 해석 본문 포함) → 워크북이다. 모범 해석 전용 제목·쪽 나눔·목차 항목을 만들지 않는다. 공통 안내문은 ‘지문 분석지의 끊어읽기 해석과 비교’로 연결하고 바로 다음 쪽이라고 고정하지 않는다. 동일 간격 확대를 반복 누적하지 않는다.

통합 DOCX 하나를 수정 기준으로 누적 관리한다. 기존 최신 파일의 대상 블록만 수정하고 다른 승인 내용·서식을 보존한다. ‘최종 출고’ 요청은 [전체통합본과 분권 5개](split-delivery.md)의 DOCX 6개를 담은 ZIP 1개 전달을 포함한다. 블로그·카페·썸네일은 별도 요청 시 파생한다. PDF는 필요한 내부 검수에 사용하며 기본 전달하지 않는다. QC/FINAL 원고·상태는 별도 관리하고 실제 독립 검수 전에는 FINAL 완료를 주장하지 않는다. 상세 수정 이력은 별도 기록에 누적 보존하고 전달 인계에는 현재 유효 요청·반영 상태·미해결 사항과 상세 이력 위치만 담는다(U48).

문항은 독립 검수자 2명이 각각 풀고 유일정답·정답 근거·네 오답의 배제 근거를 확인한다. 길이·구체성·단정 표현·문체·난도·학습 어휘 대응도 점검하며 취향 의견과 근거 있는 오류를 구분한다. 실제 독립 검수가 가능한 권한·환경에서 수행하고, 미실시 검수를 수행한 것처럼 보고하지 않는다.

기계 검사, 의미 검수, 문항 독립 풀이, 실제 DOCX/PDF 조판 검수, 저장본 재열람을 구별하여 기록한다. 검사기의 종료코드 0은 이 모든 검수 완료가 아니다. 플랫폼에서 수행할 수 없는 검수는 항목을 없애지 않고 미실시와 필요한 후속 절차를 기록한다.

기초 외래어 각주는 의미가 가장 분명한 문맥 번역을 선택하고 익숙한 외래어 표기도 허용한다(U52). 외래어만 강제하지 않는다. 세부 각주 틀은 `gloss-rules.md`를 따른다.

축약형은 S/V에도 원문 형태를 유지한다. 단, `'s`가 has의 축약형이면 `'s(has)`로 병기한다(U53). 예: `It's clear.` → `S: It, V: 's`, `It's changed.`(has changed) → `S: It, V: 's(has) changed`. 곡선 아포스트로피 `’s`도 원문 모양을 유지해 `’s(has)`로 표시한다. is/has는 문맥에서 확인하며 과거분사가 뒤에 있다는 이유만으로 has로 판정하지 않는다. 원문 영어·청크는 바꾸지 않고 표시용 설명을 분리한다.

요청된 홍보 TXT의 내용·실제 링크·미리보기 기준은 `promotion.md`를 따른다. 썸네일은 U59의 원본 보존을 기본으로 하되, U63의 별도 입력 변환 도구와 U64의 ‘모범 해석 수록’ → ‘분석지 해석 수록’ 한 곳 정정만 적용한다. 나머지 코드·문구·디자인·글꼴·배치는 보존하며 승인 범위 밖의 썸네일 이식·개선은 하지 않는다.


## 단위 끝 복습란과 제외한 응원 문구

각 공통 단위의 혼공해석지 끝에 틀린 문장 번호를 적고 다시 풀도록 하는 복습란을 유지한다(U54). 안내는 ‘지문 분석지의 해석과 달랐던 문장 번호’로 연결하고 별도 모범 해석을 되살리지 않는다. 조판은 GPT 초기 MASTER에 실제 존재하는 7.5pt 복습란 역할을 보존하여 추가 역할 `interpretation_review_line`으로 연결한다. 최신 MASTER의 다른 역할·간격을 초기 값으로 되돌리지 않는다. 복습란만 다음 쪽에 고립되지 않게 마지막 문장 블록과 함께 확인한다.

응원 문구·명언을 단위 끝에 넣는 선택 기능은 제외한다(U55). 기존 입력의 quote를 학생용 교재에 자동 출력하지 않는다. 원문에 실제 인용된 문장이나 학습 내용의 인용까지 삭제하는 규칙은 아니다.

일반 단어 각주는 중1 수준부터 그 이상을 모두 제공한다(U56). 필요한 단어만 선별하는 GPT 초안 범위를 대체한다. 더 기초적인 단어도 낯선 문맥 뜻·불규칙 활용·해석상 필요가 있으면 지원한다. 이미 정한 전치사·대명사·기능 표현의 필수 지원, 같은 위치의 결합·중복 처리, 고유명사 첫 등장 및 and·but 단독 각주 예외는 유지한다.

`be able to V`의 able 보어와 뒤 부정사까지 S/V 동사 칸에 넣지 않는다(U57). `She is able to swim.`은 `S: She, V: is`로 표시한다. 실제 be동사와 함께 쓰인 고정 숙어는 be 원형과 패턴을 표제어로 삼아 `be able to V — ~할 수 있다` 각주로 제공한다. 자세한 기준은 [각주 규칙의 숙어·구문과 전치사](gloss-rules.md#숙어구문과-전치사)를 따른다. S/V의 문법적 동사 범위와 의미 지원용 각주 묶음 범위는 같아야 하는 것이 아니다. 조동사·완료·진행·수동을 이루는 실제 동사 부분은 해당 규칙대로 표시한다.
