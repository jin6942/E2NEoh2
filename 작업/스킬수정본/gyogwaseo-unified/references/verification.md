## 구조 힌트 영한 문법 대응 강조 — 현재 기준

구조 힌트는 직역을 우선하고 `emphasis_links`로 한 문법 기능과 선정 공식 S′/A의 주어 조사 이/가를 대응시킨다. 일반 문법은 양쪽 강조를 적용하며 명시적 `ko-only-verb-construction` 동사 결합은 영어 보통·한국어 조사·연결 어미만 강조를 검사한다. 영어·한국어 대괄호 전체 강조와 `ko_emphasis_spans` 단독 지정은 최신 적용 기준이 아니다. `of ↔ 의`, `using`의 `ing ↔ 사용하여`의 `하여`, 명사절 `if ↔ 이/가 … 는지`, 전치사 from의 각주에서 고른 `에서/에서 온/에서 나온`을 해당 문맥에 대조하고 무관한 조사·다른 문법·내용어까지 강조하지 않는다. 의미 대응은 위치 검사만으로 증명하지 않으므로 독립 학습 검토에서 직접 확인한다. 생략 관계사는 최신 승인에 따라 `omitted-relative` 힌트의 괄호 표지·최소 문법 기능 대응을 확인하며 빈 링크로 통과시키지 않는다. 보충한 that/which/who/whom/when/where/why의 문법적 타당성, 괄호 보통 서식, 관계사 글자와 한국어의 최소 문법 대응 부분만의 강조, 표지 제거 후 원문 일치, 다른 원문·자료의 불변을 확인한다. 생략 접속사 that은 현재 omitted-conjunction 계약으로 따로 확인하고 주어/to에는 확대하지 않는다.

MASTER·썸네일은 이 표시 정책 보완에서 변경하지 않는다. 기존 교재 적용 여부는 해당 교재의 실제 수정·저장본 검수 기록으로 따로 확인한다. structure_hint의 대응 밑줄 허용과 한국어 파생 역할 설명만 계약에 연결한다. 이번 검사·표시 시험의 실제 실행 결과는 이번 작업의 검증 기록에 남기며 아래 과거 시험 수·교재 적용 기록을 새 실행이나 현재 교재의 대응 강조 완료로 보고하지 않는다.
