# 교과서 공통 학습 단위별 워크북 기준

공통 원고의 같은 학습 단위·어휘·핵심 문장과 연결하여 제작한다. 생성·검사 도구의 범위는 runtime-and-data.md를 따른다.

해당 과의 문제 제작에는 공통 학습 단위별 워크북을 필수로 포함한다. UNIT은 교과서의 과를 뜻하며 신규 관리 표기다. 기존 LESSON·과 표기는 `workflow.md`에 따라 보존한다. 문제 제작팀은 최신 해석·분석 FINAL과 권위 원문으로 제작하며, 독립 문제검수팀은 워크북 전체를 반드시 검수한다. 필수 구성이나 검수가 빠진 상태에서는 문제_FINAL을 확정하지 않는다. `analysis-content.md`의 ‘수량 예외와 보고’에 해당하며 보고·기록까지 마친 항목은 실제 수로 구성 완료 여부를 검수한다.

**공통 학습 단위 = 해석지 단위 = 분석 단위 = 워크북 1개**로 구성한다. 원문 단락이 6문장 이하이면 그 소제목 전체를 묶는 사용자 규칙을 `editorial-core.md`와 `analysis-content.md`에 따라 적용한다. 소제목 없는 짧은 원문 단락은 실제 원문으로 묶음 범위를 확인한다. 문제 제작에서는 이 절차로 이미 확정한 단위를 이어 쓴다. 줄바꿈·쪽 나눔·제목만으로 단위를 만들거나 문제용 발췌마다 워크북·핵심 문장 활동을 새로 만들지 않는다. 별도 추가 읽기는 실제 독립 본문이고 요청 범위에 포함된 경우만 포함한다. SOURCE는 독립 본문 식별자이며 각 단위에 원래 과목·출판사·저자·과·실제 영역·단락과 출처 문장 번호를 연결한다. 원문 경계·순서·출처 문장 번호를 보존한다.

공통 학습 단위마다 워크북 한 개를 만들고 **실전문제 1문항**을 둔다. 같은 공통 단위의 분석에서 확정한 유반 세트(기본 3세트)를 뜻 쓰기와 실전문제 영어 선택지의 재료로 사용하며, 핵심 문장 다시 해석하기(기본 2개)도 공통 학습 단위마다 적용한다. 소제목 묶기를 적용한 공통 단위에서도 원문 근거가 부족하면 확정 단위를 유지하고 실제 확정 수로 제공하며, 예외 단위·원문 문장 범위, 네 항목별 기준수→실제수와 이유를 사용자에게 보고하고 작업기록에 남긴다. 수량 예외를 미해결이나 필수 구성 미완료로 자동 판정하지 않는다. 정해진 문항 수와 동학년 모의고사 수준의 분량은 유지한다. 실전문제는 과 안의 필요한 연속 원문에서 학습 단위 경계와 무관하게 고르되 해당 단위의 유반 의미 학습 연결을 유지한다. 길이·범위는 `assessment-content.md`를 따르며 문제용 범위가 학습단위 경계를 바꾸지는 않는다.

## 구성과 시험지 원칙

확정 공통 학습 단위마다 다음 순서를 유지한다.

1. 오늘의 낱말: 핵심 낱말·숙어 뜻 쓰기
2. 유의어·반의어 뜻 쓰기
3. 실전문제: 해당 공통 단위의 유반 의미를 확인하는 영어 선택지 1문항
4. 구문 결합해서 해석하기: 분석의 기본·보충 항목마다 공식·낱말 뜻을 지원하는 연습 1개
5. 핵심 문장 다시 해석하기: 기본 2개, 수량 예외는 실제 수를 제목에 표시

본문 전체 문장의 주어·동사 찾기·끊어읽기·해석 활동과 그 정답은 워크북에 넣지 않는다.

워크북은 학습 내용을 스스로 확인하는 시험지다. 1·2번 낱말 활동은 영어 표현과 뜻 쓰기 발문·응답 공간을, 5번 핵심 문장은 번호·영어 원문·응답 공간을 제공하고, 3번 실전문제에는 해당 유형의 지문·선지도 제공한다. 이 활동에는 품사, 뜻풀이, 단어 각주, 구조 힌트, 정답 예시, 미리 표시한 S/V·끊어읽기, 유의어·반의어 관계를 알려 주는 기호나 묶음을 넣지 않는다. 승인된 4번 구문 결합 연습만 번호가 붙은 영어 구절·해석 빈칸 바로 아래 도움말에 배운 공식·문맥 뜻과 해당 낱말 뜻을 제공하며 결합된 정답은 학생용에 넣지 않는다. 4·5번은 DOCX와 TXT 모두 제목 아래에 별도 지시문을 넣지 않고 바로 첫 문항을 둔다. 정답 영역은 학생용 문제와 구분한다. 워크북 실전문제와 별도 미니 모의고사는 정답·해설 영역에도 단어 각주를 넣지 않는다.

오늘의 낱말·유의어/반의어 단어시험과 해당 정답표에는 `1, 2, 3, …`처럼 일반 숫자만 사용한다. 공통 단위별·활동별로 1부터 시작하고 `W01`, `V01` 같은 영문 접두어나 앞자리 0을 붙이지 않는다. TXT의 실제 문항 번호부터 이 규칙을 적용한다.

## 1. 오늘의 낱말

학생용 오늘의 낱말과 유의어·반의어 뜻 쓰기 표의 영어 표현은 10pt이며 기존 글꼴·색·굵기·답안 공간을 유지한다. 정답표 한국어나 분석지 유반 서식과 구별한다.

선정 시 해석의 핵심성과 다의어 함정을 우선 고려한다. 확정 목록과 각주 ★를 연결하고 같은 단위에서 반복 등장할 때도 표시한다. 각주 수의 절반 상한은 적용하지 않는다.

- 해당 공통 단위의 이해와 시험 변형에 중요한 낱말·숙어를 최대 8개 고른다. 수를 억지로 채우거나 문법 틀·일반 기능어를 넣지 않는다.
- 학생용에는 확정 영어 표현과 뜻 쓰기 발문만 둔다. 일반 정규과거 -ed는 원형·기본 뜻, 불규칙 과거는 현행 표기를 유지한다. 수동·완료에서 선정된 p.p.와 독립 p.p.는 실제 형태·문맥 뜻을 유지한다. 예: 본문 had struggled의 오늘의 낱말은 `struggled — 애썼다`이며 struggle로 바꾸지 않는다. 이번 각주의 능동 완료 원형 규칙은 이 기존 오늘의 낱말 규칙을 자동 변경하지 않으며 원형 각주와 실제형 오늘의 낱말의 source_gloss_id 연결은 보존한다. 일반 -ing 분리 원형 기준은 유지한다. 품사·원형 풀이·문맥 설명은 학생용에 덧붙이지 않는다. 실제 원문 위치와 각주 ★ 연결은 보존한다.
- 정답은 문항 번호와 문맥상 한국어 뜻만 담은 간단한 표로 제시한다. 근거 문장·개별 해설·오답 분석은 붙이지 않는다.

## 2. 유의어·반의어 뜻 쓰기

- 출제 어휘는 해당 공통 단위 지문분석지의 실제 확정된 유반 세트(기본 3세트)에서 가져온다. 수량 예외가 있으면 실제 세트 수를 따르고 다른 공통 단위의 항목·창작한 관계·중복 항목으로 채우지 않는다. 이 확정 세트는 뒤 실전문제의 영어 선택지를 만드는 재료이기도 하다. 유의어의 품사·문맥 및 반의어의 실제 반대 관계는 제작·검수 단계에서 확인한다.
- 학생용에서는 실제 확정 세트의 표제어·유의어·반의어를 개별 어휘로 풀어 섞어 제시한다. 문항 번호와 정답 수도 실제 출제 어휘에 맞춘다. 세트별 묶음, 표제어/유의어/반의어 라벨, 화살표, 등호, 대조 기호로 관계를 알려 주지 않는다.
- 각 영어 표현의 한국어 뜻을 쓰는 문제로 만들며, 정답도 번호와 뜻만 담은 간단한 표로 제시한다. 어휘 관계 해설은 넣지 않는다.

### 낱말 정답표

- 오늘의 낱말과 유의어·반의어는 공통 단위별·활동별로 구분하여 번호를 학생용과 일치시킨다.
- TXT와 DOCX 모두 번호와 뜻을 행 순서대로 3열에 배치한다. DOCX는 테두리 없는 workbook_answer_grid 역할을 사용하여 오른쪽 여백을 활용하고, 마지막 남는 셀은 빈칸으로 둔다. 기존 글자 크기·번호 강조와 모든 뜻을 보존한다.
- 답안 내용은 생략하지 않고, 임의의 표 재설계·행 압축·여백 늘리기로 승인 MASTER 배치를 바꾸지 않는다.
- TXT에도 실제 번호와 뜻이 채워진 표를 넣는다. 제작방은 이를 같은 DOCX에 내장 MASTER 답안 형식으로 반영한다.

## 3. 실전문제

- 유반이 있는 단위의 워크북 실전문제는 해당 공통 단위에서 배운 실제 확정 유반 세트(기본 3세트)를 선택지 재료로 삼아 영어 선택지를 만든다. 원문 근거 부족으로 유반 0세트를 실제 보고한 단위는 일반 실전문제로 출제하며, 오늘의 낱말이나 존재하지 않는 유반을 억지로 넣지 않는다. 학습한 어휘의 의미를 문맥 속에서 구별할 수 있는지 평가한다. 한 문항에 3세트 전부·9어휘 전부 등 사용자가 정하지 않은 활용 최소 수량을 강제하지 않는다. 유의어를 정답·반의어를 오답으로 고정하거나 그 역할을 일률적으로 뒤집지 않으며, 발문·문맥에 따라 반의어도 정답이 되고 유의어도 오답이 될 수 있다. 역할 비율·교대 순서를 기계적으로 강제하지 않는다. 상세 기준은 `assessment-content.md`의 5항을 따른다.
- 제목·주제·요지·주장·목적·심경·분위기·내용·함축 의미·빈칸·요약 등의 후보 중 해당 공통 단위의 유반을 영어 선택지에 활용하여 의미 학습 여부를 실제로 판단하는 유형만 출제한다. 순서·삽입·무관한 문장, 본문 번호로 답하는 어휘 등 그 목표에 맞지 않는 유형은 별도 미니 모의고사에서 다룬다. 학습 어휘를 장식적으로 넣거나 본문 번호만 제시한 것을 유반 의미 판단 문항으로 처리하지 않는다.
- references/assessment-content.md의 출제 기준을 적용한다. 워크북 실전문제를 별도 변형문제로 복제하지 않으며 Q01부터 전체에서 중복 없는 번호를 부여한다.
- 편성표에서 모든 대상 공통 단위와 실전문제가 1:1로 대응하는지 확인한다. 한 본문에 여러 공통 단위가 있는데 본문 전체 실전문제 1개로 대신하지 않는다. 별도 미니 모의고사는 공통영어1·2에서 5문항 × 3회분(15문항), 영어II(영어2)에서 7문항 × 3회분(21문항)이며 워크북 문항 수에 합쳐 세지 않는다.
- 실제 원래 문항 유형이 있는 경우 그 유형을 제외하며, 원유형이 없는 일반 본문은 없음으로 기록하고 유형을 추정하지 않는다. 어법 유형은 출제하지 않는다. 정답 하나만 성립하는지 확인한다.
- 독립 본문을 식별하는 SOURCE와 실제 문항의 SOURCE_RANGE를 구분한다. 동일 발췌 구간을 포함하여 워크북 실전문제·모든 모의 회차에서 TYPE 반복을 허용하되 같은 문제를 복제해 문항 수를 채우지 않는다. 가능한 수능 독해 유형을 다양하게 배분하되 워크북의 유반 의미 판단 목표·지문 적합성·유일정답을 우선한다. 상세 유형 분류, 발췌 허용 조건과 원문 보존은 `assessment-content.md`를 따른다.
- 발문·지문·선지와 정답·정답 근거·해설·네 오답의 개별 분석을 빠짐없이 싣는다. 영어 선지 해석은 해설 영역에만 둔다.
- 학생용과 정답·해설 영역 모두에 단어 각주를 넣지 않는다. 문장 표시·빈칸·밑줄 등 해당 유형을 성립시키는 출제 표시는 유지한다.

## 4. 구문 결합해서 해석하기

- 실전문제 뒤 **새 페이지**에서 4번 제목과 연습을 시작한다. 같은 페이지에서 이어 5번 핵심 문장으로 진행하며 5번 앞의 별도 강제 쪽 나눔은 제거한다. 실제 넘침은 기존 글자 크기·필기 공간을 줄이지 않고 Word에서 확인한다.
- 분석의 기본 항목과 승인된 보충 항목을 모두 같은 순서의 워크북 ‘4. 구문 결합해서 해석하기’에 1:1로 연결한다. 학생용은 번호가 붙은 영어 구절·해석 빈칸을 먼저 두고, 바로 아래 도움말에 배운 주초점 공식·문맥 뜻 → 실제 연습 범위의 필요한 보조 기능·낱말 뜻 순서로 제공한다. 결합된 한국어 답은 정답지에만 둔다. 공식과 낱말 뜻은 기존 승인 내용과 일치시키며 원문 전체를 반복 해석하는 활동으로 늘리지 않는다. 동사 구문의 불필요한 A/B 풀이를 빼거나 묶음 각주의 실제 연습 낱말만 지원할 때는 manuscript-data.md의 검토된 support_overrides를 적용한다.
- DOCX와 TXT 모두 4번 제목 바로 다음에 첫 문항을 두며 ‘도움말을 결합하여 우리말로 해석하세요’ 같은 별도 지시문은 넣지 않는다. 각 문항의 영어 구절·해석 빈칸 다음에 해당 도움말을 둔다. DOCX에서는 문항과 그 도움말만 함께 두며 도움말을 다음 문항이나 5번 제목과 이어 묶지 않는다. 기존 내용·글꼴·크기·간격·답안 공간은 유지한다.
- 도움말 안의 지원 순서는 분석에서 배운 주초점 공식과 문맥 뜻, 같은 문장의 기존 보조 기능·낱말 각주 뜻이다. can/can be·완료나 along/by/through처럼 실제 구절을 정확히 해석하는 데 필요한 지원은 기존 같은 문장 각주 ID로 연결한다. 주초점 공식과 같은 항목은 중복하지 않고 보조 지원을 두 번째 학습 초점으로 늘리지 않는다. 원 각주가 `provide A with B` 같은 동사 구문이어서 연습 범위 밖의 A/B 풀이까지 노출하면, 검토한 `practice.support_overrides`로 `provide — 제공하다`처럼 기본 동사·뜻만 좁혀 지원할 수 있다. 원래 각주를 고치지 않으며 원 각주 ID와 경로별 기본형/실제형 일치·검토 근거를 보존한다. 일반 낱말 뜻을 임의 교체하는 예외가 아니다. given·provided처럼 원형으로 지원한 능동 완료의 실제 p.p. 관계 안내는 지원을 좁혀도 보존한다. 묶음 각주의 실제 연습 낱말만 지원하는 별도 source_span 투영 경로는 manuscript-data.md를 따른다. 영문 연습은 해당 분석의 인용 범위 안에 있는 실제 원문 구절을 사용한다. 원문의 동사 형태·부정·태·양태를 바꾸지 않는다. 학생용에는 조합 후 한국어 답·정답 예시·미리 푼 구조 힌트를 넣지 않는다.
- 분석 기본 3개와 승인된 보충 각각 1개에 연습 1개를 대응한다. 기본 항목의 실제 근거 부족 예외는 유지하며 연습 수를 임의로 3개에 맞추지 않는다. 같은 공식 보충은 단위당 대표 1개로 제한하고 수동/능동 완료 외 범위를 자의적으로 추가하지 않는다. 부분 부정처럼 해당 구절을 단순 기능 공식으로 연습하면 뜻이 바뀌는 경우에는 사용자에게 실제 예를 제시하고 승인받은 경우만 명시적 예외로 연결한다. 승인된 부분 부정 분석·연습은 유지하고 같은 단위의 다른 문장으로 수동 결합을 연습한다. 예외 범위·승인 근거·원래 항목과 대체 항목을 기록하며 부분 부정을 일반 부정으로 고치거나 임의 면제하지 않는다.
- 학생용·정답은 단위마다 1부터 같은 순서로 번호를 매긴다. 정답에는 그 구절의 결합 해석만 둔다. 낱말 뜻 쓰기 정답이나 실전문제 Q 번호·회차별 문항 수에 합산하지 않는다. 데이터와 원문 근거는 manuscript-data.md의 practice·formula_routes·syntax_point_ids로 연결한다.

## 5. 핵심 문장 다시 해석하기

- 4번 마지막 도움말 뒤와 5번 제목 사이에 **빈 줄 하나**를 둔다. DOCX는 기존 워크북 빈 문단 역할을 한 번만 넣고 TXT도 같은 경계에 빈 줄 하나를 둔다. 문제와 도움말 사이 또는 5번 제목과 첫 문장 사이에 넣지 않는다. 제목·필기 공간·기존 쪽 구분은 유지한다.

- 4번 구문 결합 연습 뒤에 5번 제목과 전체 핵심 문장 활동을 함께 배치한다. 핵심 문장 1번을 앞쪽에 남기고 2번만 다음 쪽에 놓지 않는다. 계속 표제·쪽 나눔은 layout-rules.md의 최신 기준을 따른다. 같은 공통 단위의 해석지·지문분석지에서 확정된 핵심 문장(기본 2개)을 그대로 사용한다.
- 해석 다시 쓰기는 확정 공통 학습 단위마다 핵심 문장 2개를 제시한다. 짧은 공통 단위에 서로 다른 원문 문장 2개가 없으면 `analysis-content.md`의 수량 예외에 따라 실제 확보한 수만 제공·보고한다. 문장 창작·중복·다른 공통 단위에서 빌려 채우기·확정 후 임의 합침은 금지한다. 제목에 실제 수를 명시하여 기본은 ‘핵심 문장 2개 다시 해석하기’, 실제 1개면 ‘핵심 문장 1개 다시 해석하기’로 표시한다. 문제용 발췌마다 별도 핵심 문장을 고르지 않는다. 충분한 원문이 있는 공통 단위는 임의로 줄이지 않는다.
- 학생용과 정답의 문항 번호는 공통 학습 단위마다 1부터 실제 수까지 매긴다. 기본은 1, 2이며 수량 예외로 핵심 문장이 1개면 양쪽 모두 1만 둔다. 원문 문장 번호를 학생용 문항 번호로 쓰지 않으며, 출처 대조는 보존된 원문 문장 번호로 제작·검수 단계에서 별도로 확인한다.
- 영어를 줄이거나 바꾸지 않으며 학생용에는 5번 제목 바로 다음에 번호·영어 문장과 기존 ‘나의 해석’ 필기 공간을 둔다. DOCX와 TXT 모두 ‘우리말로 다시 해석하세요’ 같은 별도 지시문을 제목 아래에 넣지 않는다.
- 정답에는 각 문장에 대응하는 우리말 해석만 적는다. 근거 문장 재인용·부가 해설은 붙이지 않는다.
- 핵심 문장 전체 해석의 이 제한은 5번 코너와 같은 활동을 다른 곳에 중복한 경우에 적용한다. 승인된 4번의 짧은 구문 결합 연습과 해당 정답은 별개다. 다른 제목으로 본문 전체 해석·S/V·끊어읽기 활동이나 모범답안을 중복 배치하지 않는다. 혼공해석지·지문분석지의 원래 본문 학습 내용 및 실전문제의 상세 해설과는 범위를 구분한다.

## 최종 확인과 인계

- 확정 공통 단위·해석지 학습단위·분석단위·워크북 수의 1:1 대응, 공통 학습 단위별 실제 확정 유반 세트(기본 3세트)와 실전문제 1문항의 누락·중복, 별도 미니 모의고사의 과목별 회당 문항 수(공통영어1·2는 5문항, 영어II는 7문항)와 3회분, 다섯 단계의 순서, 4번 분석 항목↔연습↔정답의 1:1 연결과 5번의 실제 확정 핵심 문장 수(기본 2개)와 제목·문항 번호·답안 수, 단어시험·정답표의 일반 숫자 번호 대응을 전수 확인한다. 사용자 확정 묶기 외에 원문 단락을 자의적으로 재분할·합치거나 문제용 발췌에 따라 학습단위를 추가하지 않았는지 확인한다. 문단 경계가 없었던 원본은 전체를 읽고 확정한 의미 단락 범위와 대조한다. 수량 예외는 사용자 보고·작업기록과 실제 제공 수를 대조하며, 기록된 원문 부족만으로 자동 보류하지 않는다. 충분한 근거가 있는데 빠진 항목이나 내용 오류는 수정한다. 삭제 대상인 본문 전체 문장 활동과 그 정답이 남지 않았는지 확인한다.
- 저장본에서 확정 학습단위별 5번 핵심 문장과 대응 답안을 각각 세고 동일한 문장끼리 1:1로 대응시킨다. 4번의 짧은 구문 연습은 분석 항목별로 따로 대조한다. 기본은 각각 2개, 수량 예외 단위는 기록된 실제 수와 일치해야 하며 1문장 공통 단위는 문항·답안 각각 1개인지 확인한다. 전체 합계만 맞거나 핵심 코너만 맞는다고 통과시키지 않고 워크북 전체를 대조한다. 삭제한 활동의 제목·발문·문항·응답 공간·답안이 다른 위치에 남지 않았는지 확인한다. 기존 별도 QC 사본이 실제 발견되면 workflow.md의 사본 처리 절차를 따르며 새 사본을 만들지 않는다.
- 1·2·3·5번 학생용에 품사·뜻·각주·구조 표시·어휘 관계 등 허용되지 않은 힌트가 남지 않았는지 확인한다. 4번은 승인된 공식·낱말 뜻 지원의 정확성을 확인하고 결합된 정답이 노출되지 않았는지 확인한다.
- 유반이 있는 단위의 모든 워크북 실전문제에서 같은 공통 단위의 유반을 영어 선택지에 활용해 실제 의미 판단을 요구하는지 확인하고, 관계 이름만으로 정답·오답을 결정하거나 역할을 역고정·기계적 배분하지 않았는지 `assessment-content.md`의 5항에 따라 검수한다. 순서·삽입·무관한 문장 등 워크북 목표에 맞지 않는 유형이 섞이지 않았는지 확인한다.
- 해석·분석 FINAL의 변경 시 낱말·유반 세트·구문 연습·핵심 문장과 대응 답안 전체를 다시 대조한다. 낱말 뜻, 핵심 문장과 정답을 FINAL 및 원문과 대조한다. 워크북 답안의 EVIDENCE·EXPLANATION 필드를 채우기 위해 불필요한 해설을 만들지 않는다.
- 실전문제에는 정답 근거·해설·네 오답 분석이 모두 있고 유일정답인지 확인한다. 실전문제·그 해설에 단어 각주가 남지 않았는지, 낱말 정답표의 번호와 뜻이 학생용과 맞는지 확인한다. 허용 가공을 되돌린 본문이 정상 원문과 같은지 확인한다.
- 워크북 전체와 미니 모의고사·정답해설을 문제_QC_HANDOFF TXT 하나에 담고 같은 DOCX의 담당 부분에도 추가/교체한다. 별도 검수방은 같은 전체 범위를 문제_FINAL로 확정하고 확정 수정도 같은 DOCX에 반영한다. 단계별 새 DOCX를 생성하지 않는다.
- 워크북은 같은 누적 DOCX에 반영하며 전달용 교재 파일명은 references/workflow.md의 ‘혼공독해교재_과목_출판사(저자약칭)_과표시’ 기준을 따른다. UNIT은 내부 관리 ID와 인계본에 유지한다. 사용자 지정 교재 폴더의 저장·실제 저장본 재열람·인계 절차도 해당 문서를 따른다.
