# 해석지·지문분석지 내용 기준

차례: 원문·문장 → 끊어읽기 → S/V → 각주 → 구조 힌트 → 해석 → 문단별 지문분석.

통합 스킬의 대상·단위·수량·최신 사용자 결정은 `editorial-core.md`를 따른다. 등급을 언급할 때 내신과 모의고사를 구분한다. 학생이 단어 뜻과 구조 안내를 이용해 스스로 해석하고, 분석지에서 의미와 내용 이해를 확인할 수 있게 한다.

## 원문과 문장

- 지정된 교과서 권위 원본으로 본문을 먼저 확정한다. 문제용 오류·빈칸·순서·삽입이 실제로 있는 경우에만 필요한 정답 근거로 정상형을 복원한다. 일반 본문에 정답 자료나 원유형을 요구하지 않는다.
- 혼공해석지와 지문분석지는 지문 수, 문장 수, 순서, 문장별 영어가 같아야 한다.
- 세미콜론을 마침표처럼 나누지 않는다.
- 끊어읽기를 다시 붙였을 때 철자·대소문자·축약형·따옴표·구두점이 원문과 같아야 한다.
- 공통 학습 단위마다 핵심 문장 2개를 선정하고 두 자료에서 일치시킨다. 짧은 단락의 원문 근거가 부족하면 아래 ‘짧은 단락의 수량 예외와 보고’를 적용한다.

### 원문 경계와 공통 학습 단위

- 공통 학습 단위는 `editorial-core.md`의 6문장 경계와 소제목 전체 묶기 규칙을 적용한다. 소제목 없는 짧은 단락은 원문을 보고 묶음 범위를 확인한다. 확정 전 임의로 합치거나 최종 단위를 배포하지 않는다.
- 원문 PDF의 줄바꿈·쪽 나눔을 실제 단락으로 오인하지 않는다. 단락 표시가 없는 이야기·PDF는 본문 전체를 읽고 논점·사례·시간·장소·사건·화자 전환을 확인한다. 실제 원문 경계와 편집자가 구성한 의미 경계를 따로 기록한다.
- 모든 원문 문장은 정확히 한 공통 단위에 속한다. 해석지·분석지·워크북은 이 단위를 공유하며 출처 문장 번호를 다시 매기지 않는다. 과목·출판사·저자·과·본문 영역·원본 쪽/단락/문장 범위를 관리한다. 원문 제목·소제목은 문장 수에 넣지 않는다.
- SOURCE는 독립 본문, 공통 단위는 해석·분석·워크북 범위, SOURCE_RANGE는 문항의 실제 연속 발췌 범위다. 서로 바꾸어 사용하지 않는다.
- 사용자가 범위에 포함한 추가 읽기는 별도 독립 본문으로 식별한다. 본문 속 대화·직접 인용은 보존하며 별도 의사소통/듣기 영역을 주 독해 본문 요청만으로 추가하지 않는다.
- 분석지만 요청하면 기존 해석지를 통째로 다시 쓰지 않는다. 사용자 제공 해석지는 권위 원문과 문장별로 대조하고 확인한 오류·연결 항목을 요청 범위에서 처리한다.
- 공통 단위마다 제목/주제·의도/요지·전체 문장 흐름·쉬운 풀이·어법·유반을 제공한다. 전체 본문 분석 하나에 문단별 제목만 붙인 것은 단위별 분석이 아니다.

### 수량 예외와 보고

- 기본은 공통 단위마다 핵심 문장 2개·구문으로 해석하기 기본 3개·쉬운 풀이 대상 3문장·유반 3세트다. 아래 결합 공식 대표 사례의 승인된 보충은 기본 3개와 별도이며 기본 수량 부족을 보충 수로 가리지 않는다. 소제목 전체를 묶어도 문장·적합한 근거가 부족하면 실제 확보한 항목만 제공한다. 하나가 부족하다는 이유로 다른 항목도 줄이지 않는다.
- 수를 채우려고 문장·문법 근거·어휘 관계를 창작하거나 같은 항목을 중복하지 않는다. 충분한 근거가 있는 단위의 임의 감축·누락·오류는 수량 예외가 아니다.
- 대상 본문·단위·원문 문장 범위, 네 항목 각각의 기준수→실제수, 부족 사유를 사용자에게 보고하고 QC/FINAL 원고 밖 작업기록에 남긴다. 총수만 보고하거나 내부 기록만 남기지 않는다.
- 정당한 원문 부족을 보고하고 실제 수를 일치시켰다면 수량만으로 FINAL을 자동 보류하지 않는다. 내용 정확성·자료 연결·독립 검수의 다른 조건은 그대로 적용한다.
- 제목·항목·문항·정답도 실제 수에 맞춘다. 핵심 문장이 1개이면 워크북 활동명도 ‘핵심 문장 1개 다시 해석하기’로 표시한다.
- 이 예외는 해당 학년·동유형 공식 모의고사와 비교하는 문항 분량 기준, 공통 단위당 워크북 실전문제 1개, 미니 모의고사의 확정 회차별 문항 수를 낮추지 않는다. 고정 100단어 하한은 적용하지 않으며 분량을 채우려고 무관한 앞 문단을 붙이지 않는다. 문제용 연속 원문 보충은 분석 단위를 합친다는 뜻이 아니다.

## 끊어읽기

- 청크 길이의 하한은 없다. 8낱말을 넘으면 적절한 전치사·접속사 등의 경계를 다시 검토하되, 의미·문법상 경계가 없으면 유지한다. 8낱말 이하로 만들기 위해 숙어·절을 억지로 가르지 않는다(U49). 길이 신호만으로 오류나 검수 실패를 확정하지 않는다.

- 숙어·구동사·고정 표현은 가르지 않는다. 묶음 판단은 `gloss-rules.md`를 따른다.
- 명사를 후치수식하는 형용사구와 전치사구는 각각 시작 앞에서 반드시 끊는다: `a book / full of pictures`, `the people / in the room`. 형용사구 안에서 형용사의 뜻을 보충하는 전치사구는 별도 명사 후치수식으로 오인하지 않는다. `a book / full / of pictures`로 자르거나 고정 숙어 내부를 나누지 않는다.
- 수량·종류+of의 같은 어순 결합은 위 명사 후치수식 경계의 예외다. 수량·종류 표현 자체가 뒤 명사 앞에서 같은 어순의 한국어 `~의` 수식어로 대응하면 `metric tons of — (미터법) 톤의`, `some kind of — 어떤 종류의`처럼 of까지 한 각주로 묶고 표현 내부를 끊지 않는다. 해당 위치의 단독 of·중복 구성 낱말 각주는 제거하되 뒤 명사의 뜻은 별도로 둔다. 물리 단위인지 비유인지, 종류·수량 표현인지 일반 명사 후치수식인지는 실제 문맥으로 판정한다. `the amount of plastic — 플라스틱의 양`, `the destruction of nature — 자연의 파괴`처럼 어순이 뒤집히는 일반 명사구 전체에 이 예외를 적용하지 않는다. 이미 승인된 some of 등의 결합 표현은 기존 뜻으로 유지한다. 확정한 표현은 `reading_checks.protected_spans`의 `quantity-kind-of`와 통합 `gloss_id`로 연결하고, 그 표현 내부의 옛 `postnominal-preposition` 강제 경계만 제거한다. 영어 청크를 합치면 한국어 청크도 같은 수·범위로 대응시킨다. 뒤 명사 앞을 기계적으로 새로 끊지는 않는다.
- 수동태에서 ‘누가·무엇에 의해’를 나타내는 by 구는 by 앞에서 반드시 끊는다: `isn’t controlled solely / by its brain`. 유한 수동태뿐 아니라 실제 수동 관계를 나타내는 분사구에서도 같은 의미 기준을 적용한다. `by V-ing`의 수단·방법, `by which`의 관계사 연결, 기한·위치 등의 by는 이 규칙의 대상이 아니며 각 용법의 기존 경계 기준을 따른다. 한국어 청크도 같은 수로 나누고, not ... solely의 부분 부정을 전면 부정으로 바꾸지 않는다. 해당 경계를 `reading_checks.required_breaks`의 `passive-agent-by`로 기록한다. 원고의 모든 by 출현을 검토하고 해당 여부를 판정하며, 단순 철자 검색만으로 문법 관계를 확정하지 않는다.
- 그 밖의 전치사구, 접속사절, 관계사절, to부정사, 분사 후치수식 앞은 의미·문법 경계를 확인한다. 가주어 뒤 진주어 to부정사 앞은 끊는다: `It is important / to study hard.`.
- 문맥상 가주어 It과 that 진주어로 확인한 구문은 It부터 that까지 끊지 않는다. `It seems that`·`It appears that`·`It is likely that`는 예시이며 허용 목록의 전부가 아니다. that절 내부의 필요한 후치수식 경계 등은 유지한다: `It seems that the people / in the room / are ready.`. 전체 문장을 무조건 한 청크로 만들거나 이 예외를 to 진주어 구조에 확대하지 않는다. 각주에서는 실제 구문에 맞는 전체 `It … that S′ V′` 틀을 한 항목으로 제공한다.
- 접속사절 안에서 주어와 동사를 억지로 가르지 않는다.
- 영어와 한국어 끊어읽기는 같은 의미 단위를 같은 수의 조각으로 대응시킨다.
- 아래 S/V 줄의 콤마 규칙을 영어·한국어 끊어읽기의 빗금이나 원문 구두점에 적용하지 않는다.

새 제작과 이 규칙을 적용하는 수정 원고는 최상위 `rule_revision: R2026-09-23`을 기록한다. 각 문장에는 실제 검토 기록과 후치수식 필수 경계·숙어/형용사 보충어/가주어 시작 보호 범위·독립 기능 각주 목록을 `reading_checks`로 제공한다. 해당 구조가 없을 때도 검토 기록과 빈 목록을 명시한다. 자료 구조의 정확한 필드는 `manuscript-data.md`를 따른다. 검사는 선언된 경계·연결·범위·순서를 확인하며, 잘못되거나 빠진 문법 판정을 자동으로 발견했다는 뜻이 아니다. 과거 무표식 원고의 호환 검사 통과를 새 규칙 적용 완료로 보고하지 않는다.

## S/V 표기

`be able to V`의 able 보어와 뒤 부정사까지 S/V 동사 칸에 넣지 않는다(U57). `She is able to swim.`은 `S: She, V: is`로 표시한다. 실제 be동사와 함께 쓰인 고정 숙어는 be 원형과 패턴을 표제어로 삼아 `be able to V — ~할 수 있다` 각주로 제공한다. 자세한 기준은 [각주 규칙의 숙어·구문과 전치사](gloss-rules.md#숙어구문과-전치사)를 따른다. S/V의 문법적 동사 범위와 의미 지원용 각주 묶음 범위는 같아야 하는 것이 아니다. 조동사·완료·진행·수동을 이루는 실제 동사 부분은 해당 규칙대로 표시한다.

축약형은 S/V에도 원문 형태를 유지한다. 단, `'s`가 has의 축약형이면 `'s(has)`로 병기한다(U53). 예: `It's clear.` → `S: It, V: 's`, `It's changed.`(has changed) → `S: It, V: 's(has) changed`. 곡선 아포스트로피 `’s`도 원문 모양을 유지해 `’s(has)`로 표시한다. is/has는 문맥에서 확인하며 과거분사가 뒤에 있다는 이유만으로 has로 판정하지 않는다. 원문 영어·청크는 바꾸지 않고 표시용 설명을 분리한다.

| 구조 | 표시 |
|---|---|
| 주절·독립된 등위절 | `S: …, V: …` |
| 종속절·관계사절 | `[절 표지] S′: …, V′: …` |
| 주격 관계대명사가 주어인 관계사절 | `[who/which/that] V′: …` |
| 목적격 관계대명사 또는 접속사가 생략된 절 | `[(that)] S′: …, V′: …` 등 생략 위치를 밝힌 표시 |

- 같은 절의 주어와 동사는 콤마로 구분하고, 절과 절 사이에만 `／`를 쓴다. `/`로 주어와 동사를 나누지 않는다. 이끄는 말이 없는 주절은 `[주절]` 없이 `S: …, V: …`로 시작한다.
- 종속절 안에 다른 절이 있어도 S′·V′를 사용한다. 프라임 수를 늘리지 않고 대괄호의 접속사·관계사와 실제 주어·동사로 각 절을 구분한다.
- 절 단위 항목은 **원문에서 각 절이 시작하는 위치 순서**로 적는다. 문두 부사절은 주절보다 먼저 적고, 주절의 주어 안에 관계사절이 들어가면 주절 항목을 먼저 적는다. 주절만 무조건 맨 앞으로 옮기지 않는다.
- 주어의 내부 `subject_spans`는 실제 전체 명사구를 보존하며 내포절의 S′·V′도 별도로 표시한다. 긴 명사구 주어의 S/V 표시에서는 한정사·앞수식어·중심명사를 남기고 뒤수식어를 제외한다. 내부 `subject_spans`의 실제 전체 주어는 보존하며, 문법 검토 후 `subject_display_spans`와 `subject_display_review`로 표시 범위와 이유를 따로 기록한다. 명사절·동명사 주어, 부분/수량 표현, 등위 주어는 이 명사구 축약으로 의미·수·구조를 잃지 않게 전체를 유지한다. 예를 들어 `three areas where changes are already happening`은 내부 전체 주어를 유지하되 주절 표시만 `S: three areas`로 줄이고 관계절의 실제 S′·V′는 별도로 표시한다. 단어 수만으로 자동 절단하거나 중심명사 하나만 뽑지 않는다. 두 표시 필드가 없는 구형 원고는 전체 주어 출력으로 읽기 호환하며 최신 표시 검토 완료를 뜻하지 않는다. 다만 All+생략 목적격 관계절 구조는 주절 S=All로 표시하는 사용자 예외를 적용한다. `All you need is love.` → `S: All, V: is ／ [(that)] S′: you, V′: need`. 이 예외를 모든 명사구·의문사절로 확대하지 않으며 all의 문맥 뜻도 각주에 제공한다.
- 주격 관계대명사는 대괄호가 주어 역할을 이미 나타내므로 S′를 중복해서 쓰지 않는다. 관계사와 동사 사이에 부사·삽입구가 있어도 같은 규칙을 적용한다. 목적격 관계사는 뒤의 실제 주어를 S′로 적는다.
- 명령문의 생략된 주어는 `(You)`로 보충하지 않고 `V: Open`처럼 동사만 표시한다. 실제 주어가 있는 명령문에서 주어를 지우지는 않는다. 등위 동사의 공통 주어는 한 절 안에서 연결하고 별도 독립절을 만들어 내지 않는다.
- S/V 줄의 대명사는 원문 형태만 적고 `(= Scientists)` 같은 지시 대상을 덧붙이지 않는다. 대명사의 뜻과 지시 대상은 각주 규칙으로 지원한다.
- 등위접속사라는 낱말만 보고 무조건 새 주절로 분류하지 않는다. 독립된 절이면 S·V, 종속절 안에 병렬로 놓인 종속절이면 실제 범위에 따라 S′·V′를 유지한다. 문법적 범위는 사람이 원문에서 확인한다.
- 동사에는 조동사·완료·진행·수동을 이루는 실제 동사구를 적고 부사·목적어·보어는 섞지 않는다. 하나의 주어에 병렬 동사가 여러 개면 같은 절 안에 해당 동사들을 모두 표시한다.
- 같은 절의 병렬 동사는 원문에서 그 동사들을 잇는 것으로 검토한 `and`·`or`·`but`도 보존한다. 안내문의 `V1 and V2`처럼 `V: thinks and runs`로 표시하며 접속사를 공백이나 쉼표로 대체하지 않는다. 조동사와 본동사를 나눈 조각은 병렬 동사로 간주하지 않고, 다른 주어·목적어·내포절을 잇는 접속사를 가져오지 않는다. 원문 위치를 기록하는 방법은 [원고 데이터](manuscript-data.md)의 `clauses` 계약을 따른다.
- 생략된 접속사·관계대명사는 표시에서만 밝히고 원문은 바꾸지 않는다.

표기 예시:

| 원문 | S/V 줄 |
|---|---|
| When Mina arrived, the class began. | `[When] S′: Mina, V′: arrived ／ S: the class, V: began` |
| Mina opened the door, and Joon entered. | `S: Mina, V: opened ／ [and] S: Joon, V: entered` |
| The tools that the students use in the lab are expensive. | `S: The tools that the students use in the lab, V: are ／ [that] S′: the students, V′: use` |
| I know that the boy who won the prize is your brother. | `S: I, V: know ／ [that] S′: the boy who won the prize, V′: is ／ [who] V′: won` |
| The machine which usually works well stopped. | `S: The machine which usually works well, V: stopped ／ [which] V′: works` |
| I believe she is right. | `S: I, V: believe ／ [(that)] S′: she, V′: is` |

## 혼공해석지 각주

- 단어·숙어·구문 각주는 혼공해석지 전용이다. 지문분석지에는 각주를 제공하지 않는다.
- 포함 범위·한 항목 작성법·반복 제공·관계사와 전치사 처리·중복 제거는 `gloss-rules.md`를 따른다. 문맥 뜻은 같은 문장의 직역·분석 내용과 일치해야 한다.

## 구조 힌트

구조 힌트는 **영어의 어느 부분을 한국어에서 어디에 붙여 읽는지 바로 보이는 짧은 대응 표시**다. 내신 5등급제 3등급 학생도 문법 용어 설명을 거치지 않고 뜻의 연결을 볼 수 있게 한다. 등급만으로 개별 학생의 이해도를 단정하지 않는다.

### 선정과 작성

- **문법 연결 우선·한 힌트 한 초점:** 힌트 하나는 문법 연결 한 가지에 집중한다. 관계사·접속사·명사절·준동사 수식 등 문법 연결을 먼저 고르고, stop A from V-ing·help A V·allow A to V·keep A B 같은 동사 구문과 기능·낱말 결합은 후순위로 둔다. 상위 문법을 보여 주면서 안쪽 동사 구문의 A/B와 완성 해석까지 함께 넣지 않는다. 예를 들어 `way [to stop] → [막을] 방법 (to부정사 후치수식)`만 보여 주며 stop A from V-ing까지 동시에 풀지 않는다. `ways [to keep] → [유지할] 방법들`, `[by turning] → [바꿈으로써]`도 같은 원칙을 적용한다. 문법 힌트 안의 시제·태·양태를 번역에 반영하는 것은 필요하지만, 이를 별도의 기능 공식이나 두 번째 구문 설명으로 늘리지 않는다. 원문에서 더 우선할 문법 연결이 없을 때만 필요한 동사 구문 하나를 최소 범위로 보여 준다. `be called A`처럼 명명·동사와 대상의 결합을 학생이 놓치기 쉬운 구문도 후보에 포함하되 문장당 최대 2개와 문법 우선순위는 유지한다. 원문에 없는 동사 구문을 만들어 넣지 않는다. `be provided with`처럼 각주에서 한 덩어리로 제공하는 표현도, 실제 원문의 A/B 대상 연결을 학생이 놓치기 쉬워 그 연결 자체를 배우는 경우에는 동사 구문 후순위 후보로 검토할 수 있다. 뜻을 한 번 더 외우게 하려는 힌트와 구별해 `explanation`에 실제 연결 대상·필요성을 기록한다. 이 조건을 모든 숙어의 자동 후보 허용으로 확대하지 않는다. `throw away`·`feed on`처럼 그 자체 뜻을 익히는 숙어는 각주로 제공하며 그것만으로 구조 힌트 후보가 되지 않는다. `provide A with B`·`help A V`·`allow A to V`처럼 뒤의 대상·동사·준동사를 연결해 해석하는 동사 구문만 후순위 후보로 삼는다. 전치사나 불변화사가 붙었다는 이유만으로 모든 구동사를 후보로 삼지 않는다. 상위 after·that 힌트에서 동사 뜻을 보존하는 `throw … away`·`feed on` 범위는 그대로 유지한다. `what to V + do`는 승인된 표시 형식이 기능 결합일 뿐 실제 초점은 의문사+to부정사 연결이므로 단순 동사 구문과 같은 이유로 일괄 삭제하지 않는다.

- 제작·수정·검수에서는 **구조 힌트가 없는 문장도 전부 읽어 누락을 확인한다.** 해석할 때 절의 주체·대상이나 한국어 연결 어미를 놓치기 쉬운 접속사절(시간·조건·이유·양보·목적·대조 등), that 명사절, 간접의문문, 생략, 복잡한 목적어·보어 및 준동사 연결이 있으면 해당 부분의 짧은 힌트를 제공한다. 접속사·관계사의 철자가 있다는 이유만으로 선정하지 않고 실제 용법을 확인하되, 각주에 뜻이 있거나 S/V가 표시됐다는 이유만으로 어려운 연결을 제외하지 않는다. 일반 관계사절의 필수 포함 기준은 그대로 적용한다. 단순 and/but 병렬·기본 낱말 때문에 일괄 채우지 않는다. 다만 아래 빈 힌트 문장의 수동태 후순위 제공 기준을 적용한다. 새 힌트의 선정 이유는 `explanation`에, 미제공 판단은 해당 문장의 `reading_checks.review_record`에 짧게 남긴다. 학생용에 ‘힌트 없음’이나 검토 이유를 출력하지 않는다.
- 생략된 목적격 관계사·접속사 that 및 가주어·진주어를 우선 검토한다. 생략 여부와 무관하게 실제 관계대명사·관계부사절의 연결은 구조 힌트에 포함한다. who·which·that·whose·where·when·why·what 등은 철자가 아니라 실제 용법을 판별한다. 명시된 관계사를 각주와 S/V에 적었다는 이유로 힌트에서 생략하지 않는다. 기존 힌트가 같은 관계를 보여 주면 중복하지 않는다. 주어·서술어, 수식·절·소유·도치·병렬·열거의 연결을 읽는 데 필요한 최소 범위를 고른다. 이 필수 관계사 연결과 아래 빈 힌트 수동태 후보 외에 단어 각주와 S/V만으로 쉽게 읽히는 부분에는 억지로 추가하지 않는다. 구문이 포함된 절 전체를 번역하는 코너가 아니라 그 연결을 알아차릴 수 있는 가벼운 힌트로 만든다.
- 일반 힌트는 **영어 → 대응 한국어 (짧은 구조 이름표)**를 수동 줄바꿈 없이 한 줄로 쓴다. 영어에서 연결할 부분을 `[ ]`로 묶고, 한국어의 같은 부분도 `[ ]`로 묶어 한국어 어순에 맞는 자리에 놓는다. 한국어는 해당 문법 기능이 드러나는 직역을 우선한다. 영어·한국어 모두 대괄호 전체를 굵게 하지 않으며, 아래 문법 대응 강조와 동사 결합 구문 예외를 적용한다. Word의 너비에 따른 자연스러운 줄 감김은 허용하며 글씨를 줄이거나 수동 줄바꿈을 넣어 맞추지 않는다. 필요할 때 한국어의 큰 경계만 ` / `로 나눈다.
- `The protein [containing copper] → [구리를 포함한] 단백질 (현재분사 후치수식)`처럼 해당 구조와 연결에 필요한 최소 범위만 보여 준다. 후치수식의 앞 명사처럼 실제 연결 대상은 남기되, 그 구조와 무관한 주절·뒤 절과 그 해석은 넣지 않는다. with 구문은 `[With the planet becoming warmer] → [지구가 더 따뜻해지면서] (with 구문)`으로 끝내며 뒤의 `sea levels are rising`과 그 해석을 덧붙이지 않는다. 일반 힌트는 마지막 한국어 해석 뒤에 짧은 구조 이름표 `structure_label`을 괄호로 한 번 붙인다. 예: `(목적격 관계대명사 that 생략)`. 이름표는 문법 분류를 확인하는 표지이며 긴 설명문으로 늘리지 않는다. ‘찾으세요·묶으세요·연결하세요’ 같은 읽기 지시는 넣지 않는다.
- **절 연결 힌트는 연결어 + 실제 S′·V′까지만 표시한다.** 접속사절·명사절·간접의문문·관계절에서 동사 뒤 목적어·전치사 대상·추가 수식과 그 뜻은 넣지 않는다. 타동사 뒤라 문장 전체의 뜻이 완성되지 않아도 구조 연결만 보여 주는 표시이므로 목적어를 ‘필수’라며 붙이지 않는다. 주격 관계사는 별도 S′를 만들지 않고 관계사와 V′만 표시한다. be동사만으로 뜻이 잡히지 않을 때는 최소 명사·형용사 보어만 예외로 남긴다. 조동사·완료·진행·수동을 이루는 동사구의 시제·부정·양태는 유지하고, 동사 사이의 actually 같은 부사는 연속 원문을 보존하기 위해 남길 수 있다. 이 규칙은 동명사·분사·부정사·with 구문 자체의 한 연결에 필요한 대상·보어를 모두 지우라는 뜻이 아니다. 다만 그 범위를 구실로 안쪽 stop A from V-ing·keep A B 등 별개 동사 구문까지 겹쳐 풀지 않으며 위 문법 우선·한 초점 기준을 적용한다. `The protein [containing copper] → [구리를 포함한] 단백질` 같은 승인된 비정형 구문 표시는 유지한다.
- 일반 힌트의 영어는 아래 생략 관계사·생략 명사절 접속사 표시·분리 구동사 예외를 제외하고 실제 연속 원문 구절에 편집용 대괄호만 더한다. 원문처럼 생략된 말을 보충하거나 어순·활용형·구두점을 바꾸지 않는다. 생략 관계사의 괄호 표지는 구조 힌트의 학습 표시이며 원문 복원이 아니다. 관계사 힌트는 수식받는 앞 명사를, 가주어 힌트는 It~that 틀을 유지한다. 가주어의 that절도 실제 S′·V′까지만 표시하고 be의 최소 보어 예외만 적용한다. 일반 명사절은 `[that mealworms can actually feed] → [밀웜이 실제로 먹고 살 수 있다는 것]`처럼 해당 절의 시작부터 동사까지만 표시하며 바깥 means·have found·think about 등을 넣지 않는다. 표시 대괄호는 절 전체의 경계가 아니다. 내부 `explanation`에는 실제 전체 절 판정과 표시에서 제외한 범위를 구분해 보존한다.
- **생략 관계사 표시 예외:** 실제 관계절에서 생략된 관계사는 `display_mode:"omitted-relative"`와 `omitted_relative:"that"`처럼 기록한다. `that/which/who/whom/when/where/why` 가운데 선행사·격·해당 구문에 맞는 말 하나만 고른다. 예: `a few solutions [(that) we can find] → [우리[인간들]가 찾을 수 있는] 몇 가지 해결책 (목적격 관계대명사 that 생략)`. 관계절 시작에 보충 표지를 한 번만 넣고 일반형의 한 대응 쌍·선행사·최소 S′·V′·짧은 생략 이름표를 유지한다. `( )`는 보통 글씨이며 안의 관계사 글자만 한국어의 최소 대응 부분과 `emphasis_links`로 연결해 굵게+한 줄 밑줄로 표시한다. 한국어 대응은 해당 문맥의 관형어미·조사·명사 연결 등 그 관계사가 만드는 최소 문법 기능을 고르며 한 음절로 강제하지 않는다. 생략 관계사는 더 이상 빈 링크로 처리하지 않는다. 생략 접속사 that은 아래 별도 승인 모드로 구분한다. to·주어 보충이나 원문·청크·S/V·각주·완성 해석 수정으로 확대하지 않는다. 정확한 데이터 계약은 `manuscript-data.md`를 따른다.
- **생략 접속사 표시 예외:** 생략 명사절 접속사 that은 관계사와 구별해 `display_mode:omitted-conjunction`, `omitted_conjunction:that`을 사용한다. 힌트에만 `[(that) laws had to be changed] → [법이 바뀌어야 한다고] (명사절 접속사 that 생략)`처럼 표시하고, 괄호는 보통·that 글자와 실제 S′의 이/가 및 연결 어미는 굵게+밑줄로 대응한다. 생략 관계사는 기존 `omitted-relative`를 유지한다. 두 유형 모두 빈 대응 링크로 대체하지 않고 원문·청크·S/V·각주·자연 해석에 보충 표지를 추가하지 않는다. 생략된 주어·to까지 이 예외를 확대하지 않는다. `[(that) detectives also had to learn] → [형사들이 또한 배워야 한다고]`도 같은 기준이다. 해당 명사절의 실제 기능에 맞는 ~하는 것·~라는 것·~라고·~다고 등을 고르고 문장 전체 목적어까지 풀지 않는다.
- **분리 구동사 목적어 생략 예외:** `after you throw them away`는 `display_mode: "split-phrasal-verb"`로 `[after you throw … away] → [여러분[독자들]이 버린 후에] (접속사 after)`처럼 표시할 수 있다. 동사와 불변화사 사이의 목적어만 생략하고 동사·불변화사는 유지한다. 일반형의 대괄호·짧은 이름표·한국어 대응을 유지하며 `category:paired-structure`로 바꾸지 않는다. `display_pairs`는 정확히 1개이며, `display_spans`의 실제 원문 조각 정확히 2개를 ` … `로 연결한다. 두 조각 사이에는 실제 생략한 목적어가 있어야 한다. 일반 S′·V′ 사이의 부사나 수식어를 임의로 생략하는 허용 규칙이 아니며, 생략된 목적어의 한국어도 표시하지 않는다. 원문·청크·각주·완성 해석은 이 표시 예외로 변경하지 않는다.
- 짝 구조(`category:paired-structure`)는 서로 떨어진 상관어구의 연결을 보여 주는 예외다. `display_spans`로 고른 실제 원문 조각을 원래 순서대로 ` … `로 연결하고 필요하면 끝에 ` …`를 붙인다. 예: `both to hide … and to secretly crawl up to … → 숨기 위해서도 … 몰래 기어서 다가가기 위해서도 …`. 한국어도 선택한 대응 부분만 옮기며 사이에 생략한 내용이나 문장 전체의 완성 해석을 보충하지 않는다. `display_pairs`는 정확히 1개이며 `structure_label`·긴 설명문·읽기 지시는 붙이지 않는다. 영어만 표시하지 않고 영어·한국어를 함께 한 줄로 쓴다. 수동 줄바꿈 없이 Word의 자연스러운 줄 감김을 허용한다. 정확한 위치 필드는 `manuscript-data.md`를 따른다.
- **빈 힌트 문장의 수동태 후보:** 상위 문법 연결·짝 구조·필요한 동사 구문을 선정한 뒤 힌트가 비어 있고 실제 수동태가 있으면, 수동태를 후순위 기능 결합 힌트로 제공한다. 각주에 수동 표현의 뜻이 있다는 이유로 이 후보를 빼지 않는다. `is produced`는 `produced(생산된) → is produced(생산된다) (be p.p.)`처럼 낱말 뜻과 결합 후 뜻을 한 줄로 보여 준다. 실제 시제·부정·양태와 동사에 맞는 피동·상태 뜻은 보존하고 목적어·by/for 구·주어까지 덧붙이지 않는다. 기존 상위 힌트를 수동태로 교체하거나 이미 힌트가 있는 문장에 수동태를 일괄 추가하지 않는다. 형용사 보어·단순 과거형·be가 생략된 분사 수식까지 유한 수동태로 만들지 않으며, 수동태조차 없는 문장은 빈 힌트를 허용한다. 실제 후보·선정 또는 미선정 이유를 `reading_checks.review_record`에 남긴다. 출력은 `category:function-combination`·`display_mode:verb-function`·한 대응 쌍과 `lexical_step`·끝의 보통 괄호 공식·문법 대응 강조를 사용한다.
- 기능·낱말 결합은 후순위 후보다. 수동·능동 완료의 기능 결합 힌트는 `category:function-combination`, `display_mode:verb-function`에 `lexical_step`을 연결하여 `produced(생산된) → is produced(생산된다) (be p.p.)`, `find(발견하다) → have found(발견했다) (have p.p.)`처럼 한 줄로 표시한다. 왼쪽 낱말 뜻과 오른쪽 실제 동사구 결합 뜻을 구별하며 수동 뜻을 두 번 더하지 않는다. 실제 시제·태·부정·양태와 표시 범위 안의 부사는 보존하고 주어·목적어·A/B 틀·by/for 구는 덧붙이지 않는다. 공식 `formula_label`과 낱말 뜻 괄호는 보통 글씨다. 일반 진행·완료진행 등 이번 p.p. 구별 밖의 기존 힌트와 `what to V + do → 무엇을 해야 할지`는 현행 형식을 유지한다. `have been p.p.`나 `be being p.p.`를 여러 단계의 더하기 식으로 쪼개지 않는다. 수동·능동 완료 각주는 용법에 맞춘 기능/낱말 한 쌍에 연결하고, 승인된 `lexical_step`은 기본 낱말 뜻 하나만 왼쪽에 둔다. 정확히 한 `display_pairs`를 사용하며 별도 단계별 쌍·대괄호·`structure_label`·수동 줄바꿈을 넣지 않는다. 공식 괄호는 새 `formula_label`에서 출력하며 일반형의 구조 이름표와 구별한다. 실제 문법 표지와 한국어 기능 뜻만 대응 강조하고 동사구 전체를 자동 강조하지 않는다.
- 문장당 최대 2개이며 포함 관계는 더 우선하는 문법 연결 하나를 남긴다. ‘포함 힌트 합치기’는 서로 다른 두 문법·구문의 설명과 전체 번역을 합치라는 뜻이 아니다. 같은 포함 범위를 여러 힌트로 쪼개 두 초점을 우회해서 제공하지 않는다. 짝 구조는 기능 결합보다 먼저 검토하며 기능 결합은 후순위다. 일반 힌트는 대응 쌍 1개를 기본으로 하며 기존 최대 3쌍 범위 안에서 원문상 필요한 연결만 보여 준다. 복수 쌍도 한 문법 초점을 보여 줄 때만 허용하며, `영어 → 한국어 / 영어 → 한국어 (이름표)`처럼 같은 줄에 연결하고 이름표는 끝에 한 번만 붙인다. 짝 구조·기능 결합의 한 쌍 제한을 여러 힌트로 쪼개 우회하지 않는다. 모든 문장의 완성 해석을 추가하는 코너로 확대하지 않는다.
- 상세 문법 판정·선정 근거는 내부 원고의 `explanation`에 보존한다. 동명사/현재분사, 관계사의 격과 연결 대상, 부정사 용법, 생략·도치·병렬 등은 원문에서 검수한다. 학생용 힌트와 대응 FINAL에는 일반형의 짧은 `structure_label`만 출력하고 내부 설명문을 자동 출력하지 않는다. 각주·S/V·분석지 구문으로 해석하기의 기존 규칙은 그대로 유지한다.
- 전치사+관계대명사 각주는 `전치사 + 관계대명사 S′ V′ — S′(이/가) V′하는`으로 통일한다. 실제 문맥에서 이 틀을 적용하면 뜻·시제·관계가 손상되는 예는 강제로 고치지 않고 `reading_checks.review_record`에 원문·문장/각주 ID·적용 불가 이유·문맥상 뜻을 남겨 1차 L 독립 검수 때 사용자에게 보고한다. 일반 전치사·간접의문문·그 밖의 관계사에 이 통일 기준을 확대하지 않는다. 예: `by which S′ V′ — S′(이/가) V′하는 (관계대명사)`. 구조 힌트·분석 연결도 같은 관형 관계를 보여 주고, 영어 전치사+관계대명사 전체와 한국어 S′ 조사·관형 어미를 대응시킨다. by 하나를 주격 조사 뜻으로 설명하지 않는다. 적용 불가 예를 기록할 때는 자연 해석을 표준 틀에 맞춰 훼손하지 않는다.
- 쉼표 뒤 계속적 which의 연결 뜻은 `gloss-rules.md`의 문맥 기준을 따른다. 추가 설명·병렬의 ‘그리고’와 실제 대조·전환의 ‘그런데’를 구별하고, 각주·구조 힌트·분석지 끊어읽기 및 자연 해석에서 같은 관계를 표현한다. which라는 이유만으로 대조 의미를 만들지 않는다.
- 전치사+관계대명사는 위 통일 기준과 적용 불가 기록을 먼저 확인한다. 그 밖의 과거 관형 관계절은 실제 과거 연결을 보존해 `who V′ — V′했던 (관계대명사)`처럼 제공하고 힌트·연결 분석에도 `저질렀던`, `하고 싶어 했던` 등 맞는 관형 연결을 쓴다. 모든 관계절을 과거로 만들거나 계속적 which의 `그리고/그런데`를 `~했던`으로 바꾸지 않는다. 자연 해석은 문맥에 맞게 유지하며 연결 어미를 기계적으로 강제해 의미를 훼손하지 않는다.

without V-ing가 초점이면 `[without leaving behind] → [남기지 않고서는] (without V-ing)`처럼 그 구문만 남긴다. 앞의 `never leave a crime scene` 주절과 완성 해석까지 붙이거나 두 구조를 합친 이름을 새 학습 초점으로 만들지 않는다. 분석지에서도 사용자가 고른 without V-ing 공식의 성분과 해석 연결을 설명한다.

생략 that의 `laws had to be changed` 등 위 예시는 기존 사용자 승인 문맥의 대응 표시다. 그 한국어 시제를 다른 원문에 그대로 복사하지 않는다. 별도 문장에서 과거의 의무를 뜻하면 `~해야 했다고`처럼 시간 관계를 보존하고, 간접화법의 시제 일치인지는 실제 앞뒤 문맥에서 확인한다.

### 대명사와 지칭 대상

- 기존 힌트의 **실제 표시 영어 안**에 인칭·지시·소유·재귀 대명사가 있으면 한국어 대명사를 유지하고 바로 뒤에 `[지칭 대상]`을 붙인다. 대명사를 지칭 명사로 바꾸거나 생략하지 않는다. 앞 명사를 대신하는 `one/ones/others`도 포함하며 수사 one은 제외한다. 가주어·비인칭 it, 관계사·접속사 that/which, 공식 자리 A/B, `these algae`처럼 명사를 꾸미는 지시 한정사는 대상이 아니다. 표시 범위 밖에서 생략한 대명사를 다시 넣지 않는다.
- 지칭 대상은 같은 문장의 각주와 앞뒤 문맥에서 확인하고 짧은 명사구·내용 요약으로 적는다. `they → 그것들[문어들]`, `we → 우리[인간들]`처럼 실제 단복수를 맞추되 불가산명사·집합 표현·명제나 사건을 가리키는 this/that에 `들`을 강제로 붙이지 않는다. 예: `그것[플라스틱 쓰레기]`, `이것[문어가 팔을 잃는 일]`, `그 점[저온에서 산소를 더 잘 운반하는 능력]`. 단어 끝의 s나 한국어 명사만 보고 수·지칭 대상을 자동 결정하지 않는다. 불명확하면 원문·문장/각주 ID·가능한 해석과 불명 사유를 `reading_checks.review_record`에 남겨 내용 검수에서 보고하며 참조어를 발명하지 않는다.
- 조사는 참조 괄호 뒤에 두되 **한국어 대명사 본형**에 맞춘다. `그것들[문어들]이`, `그것[문어]이`, `우리[인간들]가`, `그것[문어]의`로 쓴다. `its own`의 `그것[각각의 팔] 자신의`처럼 별도 own의 뜻도 유지한다. `the one [(that) it lost] → [그것[문어]이 잃었던] 것[팔]`처럼 영한 어순이 달라도 실제 대응을 보존한다.
- 대명사·지칭 대상·참조 괄호는 보통 글씨다. 기존 문법 초점의 조사·연결 어미만 굵게+밑줄로 유지하고 삽입 후 위치를 다시 맞춘다. `the fact [that they can recognize] → [그것들[문어들]이 알아볼 수 있다는] 사실`에서 기존 that의 대응인 `이`·`다는`만 강조하며 참조어를 강조 범위에 흡수하지 않는다.
- 참조 괄호는 `display_pairs.pronoun_refs`로 명시한다. **선언한 한국어 참조 괄호만** 문법 대괄호의 수·범위·중첩 검사에서 제외하며 기존 영한 문법 괄호 대응은 그대로 검사한다. 선언 없는 중첩 괄호나 임의 주석을 허용하는 예외가 아니다. 위치 계약은 [원고 데이터](manuscript-data.md#구조-힌트의-대명사-참조)를 따른다.
- 이 규칙은 기존 구조 힌트 한국어의 참조 표시를 보완한다. 문법 범위·직역의 서술 내용·표시 영어·원문·청크·S/V·각주·정식 해석을 바꾸지 않는다. 단독 you의 각주 제외는 그대로이며, 힌트 안의 `여러분[독자들]` 참조 표시와 별개다. 별도 후속 승인된 3인칭 단수 일반동사의 원형 각주·명사의 복수형 보존은 [각주 활용형 기준](gloss-rules.md#실제-형태와-활용형)에만 적용하며 구조 힌트의 실제 영어 활용형은 바꾸지 않는다.

### 영어·한국어의 문법 대응 강조

아래 `using her …` 예시는 강조 위치만 설명하는 단편이다. 실제 원고에서는 앞뒤 문맥에서 her의 지칭 대상을 확인하고 `pronoun_refs`를 추가한다. 원고 전체에서도 불명확하면 위 기준에 따라 기록·보고한다.

- **독립 p.p. 낱말 대응 예외:** 같은 문장의 각주가 `held — 개최된`이면 `the fair [held in 1940] → [1940년에 개최된] 박람회`에서 영어 held와 한국어 **개최된 전체**를 굵게+밑줄로 연결한다. ‘된’만 고르지 않는다. `participle_focus_gloss_id`로 독립 p.p. 각주를 연결하고 실제 p.p. 위치와 양쪽 전체 낱말 뜻을 기록하며 수동 기능 결합 전체에 자동 확대하지 않는다. by/without+V-ing처럼 기능 공식이 따로 있으면 기존의 고정어·ing↔기능 뜻 대응을 유지한다.

- 구조 힌트의 영어는 기존 색, 한국어는 검정(000000)을 유지하되 둘 다 보통 글씨를 기본으로 한다. 선택한 **한 문법 기능**의 영어 표지와 한국어 공식 뜻을 대응시켜 굵게와 한 줄 밑줄을 적용한다. 동사 결합 구문 자체를 힌트로 선택했을 때만 `emphasis_policy:"ko-only-verb-construction"`을 명시해 영어는 보통 글씨로 두고 한국어의 대상·주체 조사와 연결 어미만 굵게+한 줄 밑줄로 표시한다. 돕다·제공하다 같은 동사 낱말 뜻 전체는 강조하지 않는다. 내부 `emphasis_links`의 실제 영한 대응은 양쪽 모두 보존한다. 관계사·접속사·가주어·It is not until·without/by+V-ing는 이 예외가 아니며 영어와 한국어를 함께 강조한다. 기능 결합형·짝 구조·생략 관계사·생략 접속사에는 이 정책을 적용하지 않는다. 대괄호 자체와 대괄호 안 전체, 명사·내용어 전체를 자동 강조하지 않는다. 7.5pt·문단 간격·한 줄 대응은 유지하고 교재 전체의 색을 바꾸지 않는다.
- 한국어는 문법과 뜻의 연결이 바로 보이는 직역을 우선한다. 예를 들어 `a career [of more than thirty years] → [30년 이상의] 경력`에서는 `of ↔ 의`만 강조한다. ‘30년이 넘는 경력’처럼 의역한 뒤 `이`·`는`을 of의 뜻인 것처럼 연결하지 않는다. 문맥 의미·부정·시제·양태는 보존하며 억지 일대일 직역으로 의미를 왜곡하지 않는다.
- `[using her miniature crime scenes] → [그녀의 범죄 현장 미니어처를 사용하여]`에서는 `using`의 **ing**와 `사용하여`의 **하여**만 짝지어 강조한다. use/사용에 해당하는 낱말 뜻까지 밑줄을 넓히지 않는다. `[if the scene in the miniature resulted] → [미니어처 속의 현장이 비롯되었는지]`에서는 명사절 접속사 `if`를 공식 `S′(이/가) V′하는지`의 주어 조사 `이`와 연결 어미 `는지`에 대응해 강조한다. 같은 문장의 각주도 그 용법·뜻과 맞아야 한다.
- 전치사 뜻은 같은 문장의 각주에서 선택한 문맥 뜻 전체에 대응한다. `from — ~에서`이면 `에서`, `from — ~에서 온`이면 `에서 … 온`, `from — ~에서 나온`이면 `에서 나온`을 강조한다. `detectives [not only from the US but also from Canada] → [미국에서뿐만 아니라 캐나다에서도 온] 형사들`에서 각주가 `~에서 온`이면 두 from과 대응하는 `에서`·`온`을 연결하되 `not only / but also`·`뿐만 아니라 / 도`는 함께 강조하지 않는다. 공동으로 쓰인 한국어 고정부를 여러 링크에서 중복 선택하지 않으며 같은 기능의 불연속 범위를 한 링크로 묶을 수 있다. 상관구문 자체가 초점인 다른 힌트는 그 상관 표현의 뜻만 대응한다. 한 힌트에 두 문법 초점을 섞지 않는다.
- 전치사·접속사와 준동사가 한 기능을 이루면 고정어와 자리 어미를 모두 표시한다. `without + ing ↔ 지 않고/지 않은 채/지 않고서는`, `by + ing ↔ 음으로써`, `while + ing ↔ 는 동안`처럼 실제 문맥의 한 뜻을 연결한다. by/without 뒤 병렬 동명사가 둘이면 두 동사의 ing를 모두 고르고 and에 해당하는 `고`는 기능 대응에 끼우지 않는다. ‘기름으로써’의 `름`처럼 어간과 어미가 한 음절에 결합하면 필요한 최소 음절을 고르며 자모로 분해하지 않는다.
- 동사 결합의 예는 `help A V`, `allow A to V`, `stop A from V-ing`, `see A p.p.`, `persuade/train A to V`, `be called A`, `seem to V`다. 선택한 공식에서 실제 해석 연결을 나타내는 조사·연결 어미와 명시된 A 주어 조사만 한국어에서 강조하며, 돕다·제공하다 같은 동사 낱말 뜻이나 A/B 내용어 전체는 강조하지 않는다. ‘구문’이라는 이름만 보고 이 예외를 적용하지 않는다. 일반적인 to부정사 연결·관계사·가주어·It is not until 강조 틀과 by/without+ing는 양쪽 문법 대응 표시를 유지한다.
- 각 표시 쌍의 `emphasis_links`에 영어·한국어 강조 위치와 같은 문법 기능의 대응을 직접 기록하고 원문·같은 문장의 각주·선택한 문법 초점에 대조한다. 생략 관계사와 생략 접속사 that은 각각의 모드로 괄호 표지와 대응 강조를 필수 적용한다. 그 밖에 생략된 주어 등 실제 짝이 없어 빈 링크를 사용하면 `emphasis_note`에 내부 근거를 남긴다. 선정한 공식에 `S′(이/가)` 또는 `A(이/가)` 자리가 명시되어 있으면 그 자리에 실제로 들어간 한국어 주어 조사 `이/가`도 기능의 연결 어미와 함께 강조한다. 영어는 해당 공식의 실제 문법 표지에 연결하며 주어 명사 전체를 강조하지 않는다. 다른 구문의 주어 조사나 무관한 조사는 자동 강조하지 않으며, `of ↔ 의`를 `이/가`로 바꾸는 규칙이 아니다. 예전 `ko_emphasis_spans`만 있는 원고를 대응 강조 완료로 보지 않는다. 정확한 필드·위치 규격은 `manuscript-data.md`를 따른다.
- 생략 관계사와 생략 명사절 접속사 that은 각각 위 전용 표시로 보충해 양쪽 대응을 연결한다. 생략된 주어·to 등 승인 범위 밖의 요소는 강조를 만들려고 보충하거나 다른 낱말에 거짓 대응시키지 않는다. 실제 짝이 없으면 내부 빈 링크 근거를 유지한다. 한국어 한 음절에 낱말 뜻과 기능이 함께 들어가도 필요한 최소 형태를 검토하며 글자 수를 기계적으로 맞추지 않는다.
- 일반형·짝 구조·기능 결합·조동사 완료 표시의 의미 대응은 같은 원칙을 따르며, 일반형의 명시된 동사 결합 정책만 영어 표시를 보통 글씨로 둔다. 승인된 생략 표지·명시적 대명사 참조 괄호·시제태 공식 및 lexical_step의 뜻 괄호 외에 강조용 따옴표·괄호·별표·설명문을 추가하지 않는다. 기존 문구가 직역 대응을 흐리면 해당 최소 힌트의 번역을 교정하고 강조 위치를 다시 맞추되, 원문이나 별도 자연 해석을 이에 맞추어 바꾸지 않는다.

### 승인 형식 예시

```text
구조 힌트   three areas [where changes are already happening] → [변화가 이미 일어나고 있는] 세 가지 분야 (관계부사 where)

구조 힌트   a protein [that contains] → [포함하는] 단백질 (주격 관계대명사 that)

구조 힌트   The muscles [attached to the brown color cells] → [갈색 색 세포에 붙어 있는] 근육들 (과거분사 후치수식)

구조 힌트   [With the planet becoming warmer] → [지구가 더 따뜻해지면서] (with 구문)

구조 힌트   [When the muscles relax] → [근육이 이완할 때] (시간 접속사 when)

구조 힌트   [that mealworms can actually feed] → [밀웜이 실제로 먹고 살 수 있다는 것] (접속사 that)

구조 힌트   [after you throw … away] → [여러분[독자들]이 버린 후에] (접속사 after)

구조 힌트   soil [with a high acidity level] → [높은 산성도를 가진] 토양 (전치사구 후치수식)

구조 힌트   a few solutions [(that) we can find] → [우리[인간들]가 찾을 수 있는] 몇 가지 해결책 (목적격 관계대명사 that 생략)

구조 힌트   It is clear that [humans are a major contributor] → [인간이 주요한 원인 제공자라는 것은] 분명하다 (가주어 It과 진주어 that절)

구조 힌트   both to hide … and to secretly crawl up to … → 숨기 위해서도 … 몰래 기어서 다가가기 위해서도 …

구조 힌트   way [to stop] → [막을] 방법 (to부정사 후치수식)

구조 힌트   what to V + do → 무엇을 해야 할지

구조 힌트   produced(생산된) → is produced(생산된다) (be p.p.)

구조 힌트   produced(생산된) → is being produced(생산되고 있다) (be being p.p.)

구조 힌트   find(발견하다) → have found(발견했다) (have p.p.)

구조 힌트   recycled(재활용된) → has been recycled(재활용되었다) (have been p.p.)

구조 힌트   provide(제공하다) → may have provided(제공했을지도 모른다) (may have p.p.)

구조 힌트   struggle(애쓰다) → had struggled(애썼다) (had p.p.)
```

예시는 형식의 기준이며 다른 교재의 내용에 복사하지 않는다. 가주어는 It~that 틀을 유지하고 진주어의 S′·V′까지만 표시하며 be의 최소 보어 예외만 적용한다. 앞서 목적어의 중요성을 이유로 `has given us one more chance` 전체를 유지하도록 한 지시는 이 절 연결 표시 기준으로 대체한다. 관계사의 실제 수식 대상·주체·소유 관계와 표시한 동사구의 시제·부정·양태는 유지하되, 완성 해석을 만들기 위해 동사 뒤 목적어·대상을 되붙이지 않는다.

### 검수

힌트가 있는 문장만 검사하고 끝내지 않는다. 힌트가 없는 문장 전체에서 어려운 절·구문 연결을 먼저 확인하고, 필요한 힌트를 보완하거나 내부 미선정 이유를 남긴다. 접속사절 힌트는 그 절과 꼭 필요한 연결 대상까지만 보여 주며, 관계없는 주절·뒤 수식의 완성 해석을 붙이지 않는다. 접속사절·명사절·간접의문문을 관계사절로 잘못 부르지 않았는지도 확인한다. 기존 힌트가 이미 있는 문장의 같은 관계를 중복하지 않는다.

각주와의 대응은 일부 예시만 보지 않고 실제 모든 구조 힌트를 원문·같은 문장의 각주와 대조한다. 용법별 결합 각주 또는 기본 뜻+기능 공식이 힌트의 뜻·조사·연결 어미·태·시제·양태로 이어지는지 확인한다. 불필요하게 다른 동사나 연결 표현으로 바꾸지 않는다. 한국어의 정상적인 활용·어순과 확인된 대명사 지시 대상은 허용하되, 힌트에서는 문법 기능이 보이는 직역 대응을 먼저 확인한다. `of ↔ 의`를 의역의 `이/는`에 잘못 대응시키거나 다른 문법 기능을 강조하지 않는다. 힌트 범위 밖의 내용을 일치를 위해 덧붙이지 않는다. 어느 쪽의 문구를 수정해도 영한 강조 위치와 대응을 함께 다시 맞춘다.

1. 영어가 원문 위치와 대응하며 절 연결인지 구문 자체 연결인지 구별한 표시 범위를 따르는지 확인한다. 일반형은 연속 발췌한다. `display_mode:omitted-relative`에서는 관계절 시작의 승인된 `(관계사)` 표시 하나만 제거한 나머지가 실제 연속 원문과 같아야 한다. 괄호 보충이 실제 생략 관계사인지 확인하고, 그 관계사 글자와 최소 한국어 문법 기능의 대응 강조를 검사한다. omitted-conjunction은 실제 생략 명사절 접속사 that인지 별도로 확인하고 표지 제거 후 원문 일치 및 실제 주어 조사·명사절 연결 어미를 대조한다. `display_mode:split-phrasal-verb`는 실제 원문 조각 2개 사이의 목적어를 생략하고 ` … `로 연결할 수 있다. 동사와 불변화사의 실제 관계를 검토하고 일반 부사 생략으로 확대하지 않는다. 짝 구조는 display_spans의 조각이 원문 순서대로 겹치지 않고 영어가 그 조각을 연결한 값과 같아야 한다. 생략 관계사/접속사 표시·분리 구동사·짝 구조의 예외를 서로 바꾸거나 겹쳐 우회하지 않는다. 한국어도 선택한 부분만 옮기며 표시하지 않은 목적어·대상이나 무관한 주절·뒤 절을 덧붙이지 않는다.
2. 일반형의 영어·한국어 대괄호가 같은 내용을 가리키고 한국어에서 붙여 읽을 자리가 보이는지 확인한다. 절 연결은 연결어와 실제 S′·V′에서 끝나는지, 주격 관계사에 별도 주어를 넣지 않았는지, be의 최소 보어 외에 동사 뒤 목적어·대상을 붙이지 않았는지 확인한다. 관계사 앞 명사와 가주어 It~that은 보존하고 일반 명사절의 바깥 동사는 제외한다. 구문 자체의 힌트는 선택한 한 문법 연결의 필요한 대상만 유지하고, 안쪽 동사 구문의 A/B 풀이를 겹쳐 넣지 않는다. 실제 표시한 주어·동사의 부정·양태·시제와 수량은 바꾸지 않으며 대괄호를 절 전체의 경계로 오인하지 않는다.
3. 연결을 보여 주는 대응 뜻을 먼저 제공하고 일반형의 짧은 구조 이름표만 한국어 뒤에 한 번 붙였는지 확인한다. 이름표가 긴 문법 설명문이나 읽기 지시로 늘어나지 않게 한다. 기계 검사의 구조 통과를 학생 이해도 검증으로 보고하지 않는다.
4. 원문에서 실제 관계사절을 먼저 찾고, 명시된 관계사와 생략 관계사의 연결이 모두 힌트에 들어갔는지 대조한다. 간접의문문·접속사절을 같은 철자만 보고 관계절로 넣지 않는다. 선행사가 있으면 수식받는 말과 해당 관계절의 최소 핵심을 함께 표시하며, 계속적 용법·소유·선행사 생략은 실제 관계를 보존한다. 문장당 2개 안에서 포함 범위는 더 우선하는 한 문법 초점으로 정리하고 후순위 동사 구문·기능 결합을 먼저 줄이며, 그래도 서로 다른 필수 관계를 담을 수 없으면 실제 원문과 함께 충돌을 보고한다. 내부 문법 판정과 실제 표시의 주체·소유·시제·부정·수동·양태가 일치하는지, 문장당 최대 2개·포함 힌트 합치기·기존 선정 우선순위가 지켜졌는지 확인한다. 조동사 완료 힌트가 `may have provided`처럼 실제 동사구만 표시하며 목적어 틀이나 그 뜻을 덧붙이지 않았는지 확인한다. 연결 각주는 조동사 완료 공식과 원형 낱말/구문을 분리하고 실제 p.p. 관계를 명시한다. 힌트 왼쪽 기본 뜻과 오른쪽 실제 결합 뜻을 확인하며 끝 공식은 보통 괄호로 표시한다. 짝 구조보다 기능 결합을 먼저 선택하지 않으며 기능 결합 후순위를 유지한다.
5. DOCX와 FINAL의 영어·한국어 문구가 일치하고, 선택한 문법 기능의 대응 부분과 동사 결합 구문의 영어 무강조 예외가 맞게 적용됐는지 확인한다. 영어·한국어 어느 쪽도 대괄호 전체에 옛 굵게 서식을 적용하지 않는다. `ing ↔ 하여`, `of ↔ 의`, 명사절 `if ↔ 이/가 … 는지`, 문맥상 `from ↔ 에서/에서 온/에서 나온`처럼 공식·각주에 맞는 짝인지 직접 읽는다. S′/A 주어 조사는 해당 공식 자리에만 포함하고 관련 없는 조사·상관 표현·내용어로 강조를 넓히지 않는다. 영어의 기존 색·한국어 검정 기본은 유지하며 FINAL TXT에는 강조용 기호나 문구를 추가하지 않는다. 모든 유형은 수동 줄바꿈 없이 한 줄로 작성했는지 확인하되 Word의 자연스러운 줄 감김은 오류로 보지 않는다. 짝 구조·기능 결합형에 추가 구조 이름표나 여러 단계의 풀이를 붙이지 않는다. 승인된 lexical_step의 기본 뜻→결합 뜻 한 줄은 허용한다. 시제태의 승인된 formula_label 보통 괄호는 유지한다.

## 직역과 자연 해석

한국어 청크는 직역 역할을 유지하고 자연 해석과 구별한다. 사용자 승인 예의 without realizing은 직역·힌트에서 ‘깨닫지 않은 채’, 자연 해석에서 ‘깨닫지 못한 채’처럼 문맥에 맞게 다르게 쓸 수 있다. 직역을 구조 힌트에만 남기고 한국어 청크에서 없애는 규칙이 아니다.

- 직역은 영어의 주어·서술어·부정·시제·수치·비교·양태·지시 대상을 보존한다.
- 대명사의 실제 지시 대상을 앞 문맥에서 확인한다.
- 수동태, 분사 후치수식, 삽입절 때문에 행위 주체가 뒤바뀌지 않게 한다.
- 편지·안내문은 높임말과 담화 목적을 일관되게 유지한다.
- 분석지에는 모든 문장의 영어 끊어읽기 → 대응 한국어 끊어읽기 → 자연 해석을 제공한다. 한국어 청크가 직역 역할을 맡고 별도 문장 직역 줄은 출력하지 않는다. 자연 해석은 매 문장 별도 작성하며 청크 결합문으로 대신하지 않는다. 정답 PDF 해석은 의미 검증 근거로 사용한다.
- 별도 모범 해석 부분·표제·전용 쪽 나눔은 만들지 않는다. 학생은 분석지 본문으로 해석을 확인한다. 해석 비교 안내와 표지 학습 순서도 이 구성에 맞춘다.
- 청크 번호·강조 등 편집 표시는 원문과 분리한다. 원문에 실제 있는 원숫자·위첨자·구두점을 자동 제거하지 않는다. 영어 조각은 원문 위치로 관리하고 각 위치에 한국어 청크 하나를 연결한다.

## 공식의 목적어 표기

- 각주·구조 힌트·어법·해설의 공식에서 목적어 자리는 `A`로 표시한다. 예: `with + A + V-ing`, `allow + A + to V`, `view + A + as + B`. 두 목적어/대응 항목이 필요하면 A·B를 사용한다.
- `with + 대상 + V-ing`, `with + 목적어 + V-ing`처럼 슬롯에 한국어 명칭을 넣지 않는다. 공식의 뜻도 `A(이/가) ~하면서`처럼 대응시킨다. 같은 문장의 각주와 구조 힌트는 조사·연결 어미를 맞춘다. 예: `A(이/가) ~하면서` ↔ `[지구가 더 따뜻해지면서]`. 다른 with 구문의 뜻은 실제 문맥에 따라 정하며 `~하면서`로 일괄 고정하지 않는다. 뒤 설명에서는 A가 실제 원문의 어떤 말인지 밝힌다. 원문 인용의 실제 목적어나 일반 설명 속 ‘대상’이라는 단어까지 A로 치환하지 않는다.

## 공통 학습 단위별 지문분석

분석지의 일반 ‘단어 및 숙어 리스트’ 표는 제공하지 않는다(U50). 분석의 필수 유의어·반의어는 유지하며, 일반 낱말 지원은 해석지 각주와 워크북의 해당 활동을 따른다. 이는 별도 단어장 제외 U46과 구별되는 분석지 내부 구성 결정이다.

- 각 공통 분석 단위에 적합한 제목 또는 주제 하나만 선택한다. 인물·사건·이야기를 잘 드러내는 이름이 적절하면 제목, 중심 내용·관계를 명시하는 표현이 적절하면 주제를 선택한다. 모든 지문에 한 종류를 강제하지 않는다.
- 원고·검수 인계에서는 `[제목] English (한국어)` 또는 `[주제] English (한국어)`처럼 종류와 같은 의미의 영어·한국어를 함께 보존한다. 학생용 DOCX는 A08에 따라 해석지·워크북에 영어(한국어) 한 줄을 배치하고 분석지에는 중복 배치하지 않는다. 원고의 대괄호 종류 표시는 내부 자료이며 학생용에 새 접두사를 임의 추가하지 않는다. 영어 제목과 한국어 주제를 다른 항목으로 짝짓거나 별도 영문·국문 주제 필드를 만들지 않는다. 교재명·과·지문번호와 원래 문항 유형을 이 항목에 섞지 않는다.
- 지문 종료 표시 `===== [/지문] =====`는 유지한다.
- 글의 의도/요지는 쉬운 한국어 1~2문장으로 쓴다.
- ‘글의 흐름’은 해당 분석 단위의 모든 문장을 원문 순서대로 한 번씩 포함한다. 각 단계의 시작 요약과 문장 범위를 구분하고 앞뒤 논리 관계가 드러나게 한다.
- 학생용 소제목은 ‘▶ 글의 의도 / ▶ 글의 흐름 / ▶ 각 문장 쉬운 풀이 / ▶ 구문으로 해석하기 / ▶ 필수 유의어 / 반의어’로 고정하고 영어를 병기하지 않는다(A09). 흐름·쉬운 풀이·어법의 문장 참조는 `[1번 문장]` 또는 `[1~3번 문장]`으로 통일한다(A10). 자연 해석 줄은 `↳ 자연 해석`으로 시작한다(A12). 실제 서식은 layout-rules의 A01~A20을 적용한다.
- 구문으로 해석하기는 원문 근거가 분명하고 **해석의 연결을 이해하는 데 도움이 되는 기본 항목 3개**를 고르며, **항목당 학습 초점은 하나**다. `title`·원문 인용 `span`·`explanation`은 모두 그 초점만 다룬다. although 양보절과 조동사 수동태처럼 독립적으로 배울 내용을 한 항목에 합치지 않는다. 두 초점이 모두 필요하면 별도 후보로 검토한다. 아래 승인된 결합 공식 대표 사례 보충 외의 항목 수를 임의로 늘리지 않는다. 가주어–진주어처럼 연결 전체가 학습 대상인 하나의 통합 구문은 기계적으로 나누지 않는다. 짧은 단락에서 적합한 근거가 부족하면 위 수량 예외에 따라 실제 확보한 수만 제공·보고한다.
- **결합 공식의 빠짐없는 학습 연결:** 수동·능동 완료의 기능/낱말 결합은 상위 구조 힌트를 교체하지 않는다. 해당 문장에서 결합 힌트로 선정되지 않은 공식은 같은 단위의 ‘구문으로 해석하기’ 대표 사례에 연결한다. 기존 기본 분석 3개를 유지하고, 그 3개에서 아직 설명하지 않은 결합 공식만 대표 사례를 보충한다. 같은 단위·같은 공식의 보충 설명은 한 번만 둔다. 다른 문장에 같은 공식의 힌트가 있다는 이유로 해당 문장의 분석 연결을 생략하지 않으며, 기존 분석이 그 공식을 설명하면 그 항목에 연결하고 추가하지 않는다. 부분 부정처럼 해당 구절을 단순 기능 공식으로 연습하면 뜻이 바뀌는 경우에는 사용자에게 실제 예를 제시하고 승인받은 경우만 명시적 예외로 연결한다. 승인된 부분 부정 분석·연습은 유지하고 같은 단위의 다른 문장으로 수동 결합을 연습한다. 예외 범위·승인 근거·원래 항목과 대체 항목을 기록하며 부분 부정을 일반 부정으로 고치거나 임의 면제하지 않는다. 완료진행 등 이번 수동/능동 완료 구별 밖의 정책을 새로 확대하지 않는다. 대상은 원고의 실제 수동·능동 완료 기능 각주이며 낱말만 보고 시제·태를 추정하지 않는다. 각 대상의 원문·공식·선정 힌트 또는 분석 항목을 `analysis.formula_routes`로 기록한다. 보충 분석은 `supplemental`의 실제 기능 각주와 이유를 기록하고 한 항목 한 초점을 유지한다.
- **배운 구문을 바로 연습:** 분석의 기본 항목과 승인된 보충 항목을 모두 같은 순서의 워크북 ‘4. 구문 결합해서 해석하기’에 1:1로 연결한다. 학생용은 번호가 붙은 영어 구절·해석 빈칸을 먼저 두고, 바로 아래 도움말에 배운 주초점 공식·문맥 뜻 → 실제 연습 범위의 필요한 보조 기능·낱말 뜻 순서로 제공한다. 보조 기능은 같은 문장의 기존 각주 ID로 연결하며 학습 초점 자체를 바꾸지 않는다. 결합된 한국어 답은 정답지에만 둔다. 공식과 낱말 뜻은 기존 승인 내용과 일치시키며 원문 전체를 반복 해석하는 활동으로 늘리지 않는다. 동사 구문의 불필요한 A/B 풀이를 빼거나 묶음 각주의 실제 연습 낱말만 지원할 때는 manuscript-data.md의 검토된 support_overrides를 적용한다. 분석 원문 인용 안에서 같은 문법 초점의 최소 연습 구절을 고른다. 각 연습은 실제 주체·시제·태·부정·양태가 보존된 답 하나와 연결한다. 같은 수동 뜻을 공식과 p.p.에서 중복 더한 답을 만들지 않는다. 정확한 필드는 manuscript-data.md, 학생용·정답 구성은 workbook.md를 따른다.
- 어법 설명은 **구문 공식·문맥 뜻 → 각 자리에 실제 원문과 각 부분의 뜻 대입 → 핵심 결합 해석**으로 쓴다. S/V/A/B 등은 해당 구조에 필요한 자리만 사용하고 모든 어법에 A·B를 억지로 붙이지 않는다. 원문 전체를 재인용한 뒤 통째로 번역하거나 ‘앞뒤를 이어 읽는다’ 같은 추상적 조언만 적지 않는다. 품사·명칭·공식 소개나 문법 시험 판별 요령만으로 끝내지 않는다. 이 대입 설명은 분석지의 구문으로 해석하기에 적용하며, 별도 구조 힌트를 여러 단계의 긴 설명으로 바꾸지 않는다.
- 대입은 낱말과 구의 범위를 정확히 구별한다. 예: `with + A + V-ing — A(이/가) ~하면서; A = the planet(지구), V-ing = becoming(~해지다), warmer = 더 따뜻한 → 지구가 더 따뜻해지면서`. becoming 자체의 뜻과 becoming warmer 전체의 뜻을 같은 것으로 적지 않는다. 보어 warmer의 뜻은 별도로 대응시킨 뒤 결합하며 뒤 주절 전체를 덧붙이지 않는다. 다른 구문도 선택한 초점의 실제 성분과 그 뜻을 확인한 뒤 합친다.
- 관계사는 실제 선행사, 관계사가 맡는 역할, 뒤 절의 실제 S/V 또는 생략된 관계사의 자리를 짚고 수식·연결 해석을 합친다. 관계대명사가 주어이면 뒤에 별도 주어를 만들어 넣지 않는다. 생략된 말은 생략이라고 설명하되 영어 원문 인용에 임의로 보충하지 않는다. although도 실제 S/V에 해당 원문과 뜻을 대입해 ‘비록 ~이지만’으로 합치고, `not ... solely`는 실제 부정 대상과 solely의 범위를 확인해 ‘전혀 ~하지 않는다’가 아닌 ‘~만은 아니다’로 결합한다. 수일치도 실제 핵심 주어·수식어·동사를 구별하여 무엇이 어떤 동작·상태에 이어지는지 보여 주는 데 필요한 만큼만 다룬다. 문법 정확도와 한 항목의 초점을 유지한다.
- 구문으로 해석하기 내용 검수에서는 공식의 자리와 실제 원문 성분·각 뜻이 대응하는지, 낱말과 구의 범위를 혼동하지 않았는지, 결합 해석의 주체·수식 대상·시제·부정·수동·양태가 맞는지 확인한다. **자리별 실제 어구 대응 없이 원문 전체와 번역만 반복한 항목은 완료로 보지 않고 고친다.** 대입을 적었다고 무관한 문법 초점이나 뒤 내용을 추가하지 않는다.
- ‘각 문장 쉬운 풀이’는 **배경지식이 필요하거나 한국어 번역만으로 뜻이 잘 잡히지 않는 내용**을 기준으로 기존처럼 단위당 원문 3문장을 선정한다. 선정한 문장은 원문 순서로 풀이하며, 단위에 1~2문장만 있으면 기존 수량 예외에 따라 실제 문장 수만큼 제공·보고한다. 설명문 수의 2~3문장 제한은 폐지한다. 구체 작성·검수는 아래 [각 문장 쉬운 풀이](#각-문장-쉬운-풀이)를 따른다.
- 유의어·반의어는 **각 확정 공통 학습 단위의 원문 핵심어를 기준으로 3세트** 제공한다. 짧은 단락에서 적합한 관계의 근거가 부족하면 위 수량 예외를 적용한다. 같은 공통 단위의 워크북 뜻 쓰기와 실전문제 선택지는 실제 확정한 세트에 대응시킨다. 유의어는 실제 원문 구문에 대입해 품사·문맥·치환 가능성을 확인한다. 타동사·자동사, 단어·구의 구조 차이를 무시하지 않는다. 일반 단어풀이 목록을 관계 세트로 제시하지 않는다.
- 반의어는 부정 접두사의 유무가 아니라 원문 문맥에서 실제 반대 관계인지 확인한다.
- 짧은 단락의 실제 근거 부족과 제작 과정의 누락·오류를 구분한다. 수량 예외의 보고·작업기록 및 해석지·분석지·워크북 실제 수의 일치를 확인하고, 누락·오류는 수정한다.
- 2026-09-26 사용자 정정으로 해석지의 노란 도입 질문(흥미 훅)은 작성·출력하지 않는다. 기존 `units[].hook` 자료는 보존할 수 있으나 학생용 DOCX와 FINAL 인계에서는 제외한다.
- 학생용 표시명과 조판은 `layout-rules.md` 및 내장 MASTER를 따른다. 쉬운 풀이 제목은 모든 교과서에서 각 문장 쉬운 풀이로 통일한다. 내부 키는 읽기 호환을 위해 유지할 수 있다.
- 내용 TXT에 시각적 여백을 만들려고 빈 줄을 반복하지 않는다. 글꼴·문단 간격·페이지 배치는 내장 MASTER와 layout-rules.md를 기준으로 제작방이 1번 단계부터 DOCX에 적용하고 후속 단계에서도 보존한다. 최초 생성·동일 파일 갱신은 `workflow.md`를 따른다.


## 각 문장 쉬운 풀이

2026-09-26 사용자 확정. 대상은 지문분석지의 ‘▶ 각 문장 쉬운 풀이’다. 교과서에서는 사용자 후속 선택에 따라 **기존처럼 공통 단위당 원문 3문장을 선정**하며, 선정 문장은 원문 순서로 배치한다. 짧은 단위의 기존 수량 예외는 유지한다. 학평 교재에서 채택한 ‘모든 문장 풀이·구문으로 해석하기 제외’는 이 스킬에 적용하지 않는다. ‘구문으로 해석하기’와 워크북 연결은 유지한다.

독자가 고등학생이어도 설명은 중학생이 읽고 바로 이해할 수준으로 쓴다. **설명문 수의 상한과 2문장 하한을 없앤다.** 직역만으로 이해되는 내용은 연결·역할을 한 문장으로 짚어도 되고, 추상적인 내용은 필요한 만큼 짧은 문장으로 나눈다. 길이를 늘리는 것 자체가 목적은 아니다.

1. **전체 흐름 속에서 연결한다.** 선정 문장마다 앞 문맥과의 연결, 이 문장이 맡는 역할(출발점·원인·예시·반전·결론 등)을 밝힌다. 문장별 뜻을 따로 전달하는 데서 끝내지 않는다. 선정한 풀이를 이어 읽어도 본문의 설명 흐름이 이어져야 한다. 선정하지 않은 앞 문장이 근거이면 그 문장 번호나 내용을 필요한 만큼 짚되 풀이 항목을 추가해 모든 문장 풀이로 확대하지 않는다. ‘1번에서 ~했다.’, ‘그렇다면 왜 ~일까?’, ‘하지만(But)으로 이야기의 방향이 바뀐다.’, ‘글 전체의 결론이다.’ 같은 표현은 실제 전개와 맞을 때만 쓴다.
2. **추상적인 뜻은 구체적인 쉬운 말로 푼다.** 직역만으로 이해되는 내용은 번역을 반복하지 않고 연결·역할만 짧게 짚는다. 비유·개념어는 학생이 아는 말로 설명한다. `modernist auction`은 ‘경매에서 값을 더 높게 부르듯, 누가 더 새로운 것을 내놓는지 점점 치열하게 겨루는 분위기’, `a musical act is a thing`은 ‘음악도 휴대폰 같은 제품처럼 보인다’처럼 해당 원문의 뜻이 드러나게 쓴다.
3. **한 문장에 한 가지 내용만 담는다.** ‘~는데, ~해서, ~하며, ~으로써’를 연달아 붙여 길게 잇지 않는다. 필요한 지점에서 문장을 끊고 설명문 수는 제한하지 않는다.
4. **주제어는 ‘~은/는’으로 제시하고 입말에 가까운 ‘~다’체를 쓴다.** ‘위대한 문학 작품에는’보다 ‘위대한 문학 작품은’으로 시작한다. 글말은 ‘~으로써 → ~해서’, ‘~함에 따라 → ~하면서’, ‘~에 의해 → ~ 때문에’, ‘~하는 바 → ~하는 것’처럼 문맥에 맞는 쉬운 표현으로 다듬는다. 이는 일괄 치환 목록이 아니다. 행위 주체를 원인으로 바꾸는 등 원문의 관계를 바꾸지 않는다.
5. **대명사를 줄인다.** ‘그것·이것·그들’은 가리키는 대상이 바로 앞 문장에서 분명할 때만 쓴다. 그렇지 않으면 ‘음악가들’처럼 실제 명사로 바꾼다. ‘필자는 이것을 물이 증발하는 것에 빗댄다’의 ‘이것’이 모호하면 문맥에 맞춰 ‘필자는 이런 일을 …’ 등으로 고친다. 이 규칙은 쉬운 풀이에만 적용하며, 구조 힌트의 `그것들[문어들]` 같은 대명사·참조 표기나 각주·S/V 규칙을 바꾸지 않는다.
6. **교과 용어처럼 들리는 말도 일상어로 다듬는다.** 문맥에 맞게 ‘단위 → 한 덩어리/한 묶음’, ‘자원 → 먹이나 살 곳’, ‘생존 → 살아남다’, ‘조정 → 변화’, ‘기능 → 쓰임새’, ‘사적인 숙고 → 혼자 속으로 고민할 때’처럼 쓴다. 이 역시 문맥별 예시이며 다른 분야의 자원·조정 등을 기계적으로 치환하지 않는다. 원문의 핵심 용어(유전, 번식 과잉, 고려 사항 생성 차단기 등)는 유지하고 바로 뒤에 쉬운 말로 풀어 준다.
7. **예시는 원리를 보여 주도록 짧고 구체적으로 든다.** 사실에 맞고, 원문이 말하는 조건·상황 안에 있으며, 오개념과 섞이지 않고, 장면보다 원리가 먼저 기억되어야 한다. 원문에 없는 가정 상황을 만들지 않는다. 기린의 긴 목을 설명하다 ‘키 큰 나무가 없는 초원에서 태어난다면’ 같은 새로운 서식 상황이나 용불용설로 오해할 설명을 붙이지 않는다. 환경이 바뀌어도 부모와 비슷하게 태어난다는 원문이라면 다음 사용자 확정 예시처럼 원리를 드러낸다. ‘어떤 새는 부모에게서 딱딱한 씨앗을 깨기 좋은 두꺼운 부리를 물려받는다. 그런데 그해에 비가 많이 와서 딱딱한 씨앗 대신 부드러운 열매가 많아져도, 새끼는 여전히 부모와 같은 두꺼운 부리를 가지고 태어난다. 유전은 그해 환경이 어떤지 따지지 않기 때문이다.’ 예시는 현재 교재의 사실 근거가 아니므로 다른 원문에 그대로 복사하지 않는다.
8. **넣지 않는 것:** 문법 설명, 번역 반복, 문제 유형·정답 이야기, 원문에 없는 사실·인과 추측, 원문보다 강한 단정, 근거 없이 특정한 인용 화자. `can help`는 ‘해결할 수 있다’로 강하게 바꾸지 않고 ‘해결하는 데 도움이 될 수 있다’처럼 가능성과 도움의 범위를 보존한다.

### 사용자 확정 전후 예시

아래는 작성 방식을 보여 주는 사용자 제공 예시다. 해당 원문·조건 없이 다른 교재 내용으로 사용하지 않는다.

- 24번 2번 문장, 전: ‘위대한 문학 작품에는 시간이 지나면서 흉내 낸 작품, 뻔한 표현, 수많은 연구와 참고서가 쌓여 작품 자체가 그 밑에 파묻히기 쉬운데, 번역은 작품을 다른 언어로 옮김으로써 이런 따분한 유명세에서 작품을 꺼내 준다.’
- 후: ‘위대한 문학 작품은 유명해질수록 흉내 낸 작품과 뻔한 표현이 많아진다. 연구서와 참고서도 계속 쌓인다. 그러다 보면 정작 작품 자체는 그 밑에 묻혀 버리기 쉽다. 번역은 작품을 다른 언어로 옮겨서, 이 따분한 유명세에서 작품을 다시 꺼내 준다.’
- 38번 8번 문장, 전: ‘생각을 표현하는 가장 작은 기본 단위는 말 하나도, 몸짓 하나도 아니다. 말과 몸짓을 합친 것이 기본 단위다. 그래서 이 단위는 …’
- 후: ‘사람이 생각을 표현할 때 가장 기본이 되는 한 덩어리는 말만도 아니고 몸짓만도 아니다. 말과 몸짓이 합쳐진 한 묶음이 기본이 된다. 그래서 이 한 묶음 안에는 몸짓처럼 그림으로 보여 주는 면과 언어처럼 정해진 칸에서 골라 말하는 면이 함께 들어 있다.’

### 쉬운 풀이 검수 체크리스트

- 선정한 풀이를 이어 읽어도 본문 흐름과 앞 문맥의 연결·역할이 설명되는가?
- 한 문장에 한 내용인가? ‘~는데/~으로써’ 등을 연쇄해 길게 잇지 않았는가?
- 주제어를 ‘~은/는’으로 제시하고 글말 표현을 뜻이 보존되는 쉬운 말로 다듬었는가?
- 대상이 불분명한 대명사가 없는가?
- 교과 용어처럼 읽히는 말을 일상어로 다듬고 원문의 핵심 용어는 바로 풀었는가?
- 예시가 사실에 맞고 원문 조건 안에 있으며 오개념을 만들지 않는가?
- 원문보다 강한 단정, 원문에 없는 내용·인과, 근거 없이 특정한 인용 화자가 없는가?

내용·연결·문체의 적절성은 해당 L 검수에서 원문 전체 문맥과 대조한다. 기계는 비어 있지 않은 설명 목록·문자열, 선정 원문 수·ID·순서를 확인하고 문장부호 기반 경고는 보조 정보로만 제공한다. 설명문 수가 3개를 넘는다는 이유로 경고·거부하거나 내용을 줄이지 않는다. 이번 스킬 수정은 기존 교재나 검수 기록을 자동 갱신하지 않는다.

## 단위 끝 복습란과 제외한 응원 문구

각 공통 단위의 혼공해석지 끝에 틀린 문장 번호를 적고 다시 풀도록 하는 복습란을 유지한다(U54). 안내는 ‘지문 분석지의 해석과 달랐던 문장 번호’로 연결하고 별도 모범 해석을 되살리지 않는다. 조판은 GPT 초기 MASTER에 실제 존재하는 7.5pt 복습란 역할을 보존하여 추가 역할 `interpretation_review_line`으로 연결한다. 최신 MASTER의 다른 역할·간격을 초기 값으로 되돌리지 않는다. 복습란만 다음 쪽에 고립되지 않게 마지막 문장 블록과 함께 확인한다.

응원 문구·명언을 단위 끝에 넣는 선택 기능은 제외한다(U55). 기존 입력의 quote를 학생용 교재에 자동 출력하지 않는다. 원문에 실제 인용된 문장이나 학습 내용의 인용까지 삭제하는 규칙은 아니다.
